## 研究生真正卡住的地方

把课题丢给 AI 之后，最常见的结果是收回来一长段像那么回事的文字。文献列了，方法也堆了，明天到底先做什么，仍然不清楚。

科研判断还不稳的人，看不出模型有没有把相关写成因果，也看不出这段话有没有把别人的结论当成自己的课题。AI 也还不熟的人，要么把模型当老师傅，要么不敢把真实卡点交出去。两边都不熟的时候，痛点会叠在一起。模型越会写，人越容易被带着跑。

生物医学和生信方向尤其明显。文献、结果和可选的下一步同时堆在面前，图表和分析一进入细节，原来的问题就看不见了。

## 这套工作流有多强

我把从入门、文献、定题，一直到开题、论文和答辩的判断顺序，写成 1 个总入口加 13 个专业 Skills。装进 Agent 之后，它会先锁定当前最值得回答的问题，再把这一步交给对的专业 Skill。每次都要求落到当前判断、下一项工作和停止条件。

这套工作流很强，因为它管的是 AI 辅助科研里最容易失控的判断顺序。研究生不必先成为方法专家，也不必先把提示词练熟。把卡点说清楚，Agent 就会按这套顺序往下走。我在真实课题推进里反复用过这套顺序，后来才把它写成可以安装的 Skills。

复杂问题走 [`meta-research-hub`](./skills/meta-research-hub/)。某一段已经明确时，也可以单独启用对应的专业 Skill。

## 你第一次会得到什么

启用总入口并说清卡点之后，第一次就会拿到这四项。

- 现在最值得先回答的问题
- 已有证据能支持什么，缺口在哪里
- 下一步具体工作，以及完成时应看到什么
- 不同结果分别怎样处理，包括继续或调整，缩小目标、转向，或者停止

有了这四项，AI 就不再只是在写一段漂亮回复。它会给出可执行的下一步。问题已经明确时，不必把 13 个专业 Skills 从头用到尾。

## 总入口怎么工作

`meta-research-hub` 是总入口。大家可以直接说明课题进到哪一步，手里有哪些证据，现在难在哪里。时间和资源有什么限制，也可以一并说。不必先整理成完整方案。

它会定位当前最需要回答的问题，再从 13 个专业 Skills 里选择合适的思路。每次建议都会写明产出和它影响的判断，下一步怎样推进，以及继续或停止前能检查的条件。

面对一批论文时，总入口会让 [`literature-mining`](./skills/literature-mining/) 先做横向比较，看不同名字的方法在输入、操作和输出上是否相近。再对关键论文做纵向拆解，把图和正文、图注和 Methods 整理成发现主线。逐篇核对输入和操作，以及筛选规则、输出语义和情境之后，才把方法标为已核验的功能等价。否则只写暂定功能相近，或推断待核实。

最后拿到的是一张带证据状态的方向地图。地图里的关系会写成观察或使用，以及支持、提示或待验证，不会把论文结论拼成当前课题的答案，也不会自动生成因果链。需要把地图用到当前课题时，再由 [`topic-convergence`](./skills/topic-convergence/) 结合自己的数据、目标和资源，筛一个值得先做的问题。如果地图还缺对象或来源，情境或读出也不清楚，会先选出一条最可核验、最可比的候选边，填一张最小验证卡，再决定是否回读文献或做预实验。

我写这套入口时，有几条判断顺序一直没变。文献用来学习问题怎样被发现、证据怎样一步步建立，并划定已知边界。项目自己的候选和结论，必须由项目自己的证据支撑。方法服务科学问题和论文主线，优先选高质量论文里常见、审稿人也熟悉的方案，并且要适合当前数据。CNS 正刊和大子刊只要有合理先例，就可以作为方法选择的基本背书。有限预算先投入能改变判断的工作。

## 13 个专业 Skills

复杂问题从 [`meta-research-hub`](./skills/meta-research-hub/) 开始。问题已经明确时，进入对应的专业 Skill。

### 发现与定题

- [`research-entry`](./skills/research-entry/) 适合研一、博一或科研入门，写出第一段可执行的学习和研究路径。
- [`literature-mining`](./skills/literature-mining/) 从高质量论文里学习问题怎样被发现、证据怎样建立，并寻找可核验的 GAP。需要时会比较不同论文实际完成的功能，重建单篇主线，给出带证据状态的方向地图。
- [`topic-convergence`](./skills/topic-convergence/) 把过宽方向、一组候选或一项矛盾结果，缩小成可验证的科学问题。
- [`innovation-judgment`](./skills/innovation-judgment/) 核对已知边界和实质重合，判断创新空间，并给出继续推进或调整方向的依据。

### 假设与验证

- [`hypothesis-construction`](./skills/hypothesis-construction/) 把观察和候选关系写成可证伪假设，并列出竞争解释与判别预测。
- [`mechanism-design`](./skills/mechanism-design/) 在表型或明确候选出现后，设计能区分竞争解释的机制验证方案。
- [`causality-rescue`](./skills/causality-rescue/) 校准因果 claim 的表达强度，分清当前证据支持相关、必要还是充分，以及是否谈得上中介或直接作用。
- [`pre-experiment-design`](./skills/pre-experiment-design/) 用规模可控的预实验，尽早判断候选或方法是否值得继续投入，并给出继续、调整或停止信号。

### 写作与交付

- [`grant-and-opening`](./skills/grant-and-opening/) 把科学问题和前期证据写成开题或标书，并写清目标、技术路线与风险。
- [`sci-writing-and-revision`](./skills/sci-writing-and-revision/) 理清论文主线和 Figure 的证据顺序，并处理正文结构与审稿回复。
- [`review-writing`](./skills/review-writing/) 搭建综述框架，区分文献结论、作者综合和待验证问题。
- [`thesis-and-defense`](./skills/thesis-and-defense/) 围绕真实研究工作，整理学位论文、外审和答辩材料。

### 投入与停止

- [`research-mindset`](./skills/research-mindset/) 面对矛盾结果、有限资源或迟迟未收敛的问题，给出投入排序和停止标准，以及下一步决定。

## 怎样安装

把仓库安装进当前 Agent。

```bash
npx skills add https://github.com/xiaojinlucky/skills
```

也可以把 `https://github.com/xiaojinlucky/skills` 直接交给 Agent。安装后启用 `meta-research-hub`，再按问题需要启用专业 Skill。无需额外配置。它是面向研究思路的文本 Skill，可在支持该格式的 Agent 环境中使用。检索、分析、实验和写作仍由相应工具完成。

## 第一次怎么问

先启用 `meta-research-hub`。大家把课题和难题说清楚即可，也可以复制下面这段，用大约 30 秒补完空缺。

```text
请用 meta-research-hub 协助我把卡住的课题收成下一步。

课题或工作阶段：
[在这里补充]

已有证据和已经做过的工作：
[在这里补充]

当前卡点：
[在这里补充]

时间、样本、数据和分析资源限制：
[在这里补充]

只提供公开或已脱敏的材料。未发表课题和原始数据，以及个人信息和私人路径，不要直接上传到外部服务。

请先给出下面四件事。
1. 现在最值得回答的问题是什么
2. 已有证据支持什么，关键缺口在哪里
3. 下一步会产生什么产出，改变哪个判断
4. 不同结果分别对应继续、调整、缩小目标、转向或停止

文献和高质量论文请优先用于寻找 GAP，学习问题怎样被发现、证据怎样建立。
方法请优先选择高质量论文中常见、审稿人熟悉、适合当前数据并服务主线的方案。
探索阶段可以调整方法、参数或展示来寻找线索，但请保留关键选择，
区分探索性结果与确认性结论，不制造信号，也不隐藏决定性反证。
```

<details>
<summary><strong>三个常见场景怎么问</strong></summary>

### 从文献找 GAP

```text
我有一个大方向，但还没有具体课题。
请先重建高质量论文中的问题怎样被发现、怎样一步步建立证据和留下未解之处，
再结合我的方向寻找可以核验的候选问题。
不要把论文已有结论直接当成我的研究答案。
```

### 结果互相矛盾或不显著

```text
我的不同分析得到了相反方向的结果，或者当前结果没有达到预期。
请先判断哪一个问题最可能改变课题主线，再给出最值得先做的一项复核。
如果有必要调整方法或参数，请说明它是探索性判断还是确认性证据。
```

### 论文不知道什么时候该停

```text
我的主要结果已经齐全，但论文还在反复修改。
请先整理核心 claim 和 Figure 的证据顺序，再按对结论的影响决定补充工作先后。
请明确哪些补充会改变结论，哪些只会增加细节，并给出可以停止的标准。
```

</details>

## 它不替代什么

这套 Skills 用来整理科研问题、证据与下一步。它不能代替真实实验和实验平台 SOP，也不能代替伦理审批、临床诊疗或正式统计审查，更不能保证论文发表。开题和标书不预测中标，创新判断也不承诺期刊层级。学位论文仍须按当前学校和院系的官方规则核对。

涉及代码和正式数据分析，或图表制作、实验执行时，请使用相应的专业工具。本系列负责让这些工作围绕清楚的问题、证据和主线展开。
