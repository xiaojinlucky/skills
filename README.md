## 你可以用它解决什么

`meta-research-hub` 是这套科研思路流的总入口。你不需要先把课题整理得很完整，只要把当前最真实的卡点说出来。

- **从高质量论文发现 GAP**：学习作者怎样发现问题、筛选信号和升级证据，而不是把别人的生物学结论直接搬成自己的答案。
- **把大方向收敛成课题**：从方向、候选、异常或矛盾结果中，找到现在最值得追的科学问题。
- **把现象压成可证伪假设**：明确适用背景、竞争解释、决定性预测，以及什么结果会让你改判断。
- **选择真正有信息增量的分析与预实验**：优先做会改变主线、候选去留或下一步的最低充分动作，而不是堆方法。
- **把结果组织成论文主线**：让 Figure、证据顺序和结论强度围绕一个核心问题展开。
- **在有限预算下决定继续、收缩还是停止**：优先修会改变结论的高影响问题；如果继续优化只剩润色，就明确停下来。

## 一条清楚的推进路径

**发现问题** → **文献找 GAP** → **课题收敛** → **形成假设** → **分析 / 预实验判断** → **组织论文主线** → **继续、收缩或停止**

每一步只问一件事：**这个动作会不会改变我对课题的判断或下一步？**

如果答案是否定的，它通常不该排在当前预算的前面。

## 先从你现在卡住的地方开始

### 只有一个大方向，不知道从哪里切
从领域认知和真实问题入手，先找到一个能判断、能推进、与当前资源相称的入口。

### 读了很多文献，还是找不到 GAP
不只摘结论，而是重建高质量论文的发现路径：它从什么未知出发、为什么锁定这个问题、哪些证据真正改变了判断。

### 候选很多，结果还互相打架
先区分技术问题、真实生物学窗口、候选边界和仍未解决的关系，再决定保留、降级、转向还是补哪一步。

### 有现象，但还不是科学假设
把“我看到什么”压成“如果这个解释成立，应该出现什么；如果不成立，什么结果会推翻它”。

### 不知道下一步该做分析还是实验
优先选择信息增量最高、成本最低、最能改变 go / no-go 的动作。预实验不是为了“做得更多”，而是为了更早排除错误方向。

### 结果已经很多，但讲不成一篇论文
从核心 claim 倒推 Figure 和证据顺序；把补充工作按影响排序，直到剩余问题不再改变主线或结论边界。

## 13 个专业方法 Skills

下面 13 个 Skill 是用户视角下的专业方法模块。复杂问题可以从 `meta-research-hub` 开始；如果你的任务已经很清楚，也可以直接进入对应 Skill。

### ① 发现与收敛

- [`research-entry`](./skills/research-entry/) — **从零建立科研入口。** 适合新手、研一/博一或刚进入新领域时建立问题意识与第一段学习路径。**边界：**不替代已经明确课题后的机制或实验设计。
- [`literature-mining`](./skills/literature-mining/) — **从文献学习“怎么发现问题”。** 用于系统读文献、判断该看什么、怎样从高质量论文提炼切入点和 GAP。**边界：**不负责具体检索软件操作，也不等于单篇论文深度解读。
- [`topic-convergence`](./skills/topic-convergence/) — **把大方向、候选或数据异常收敛成具体科学问题。** 适合“方向太大”“候选太多”“结果矛盾”这类卡点。**边界：**不负责具体课题的实质创新性审计。
- [`innovation-judgment`](./skills/innovation-judgment/) — **判断具体课题还剩多少创新空间。** 用于实质重合、GAP、被抢发后的创新窗口和投稿定位判断。**边界：**不替代前面的方向收敛，也不把焦虑本身当作创新性证据。

### ② 假设与验证

- [`hypothesis-construction`](./skills/hypothesis-construction/) — **把已有观察和候选压成可证伪假设。** 明确竞争解释、适用背景和最小验证路径。**边界：**不从零替你选方向，也不从论文拼接一个“看起来完整”的机制故事。
- [`mechanism-design`](./skills/mechanism-design/) — **把稳定表型或候选推进成可检验机制。** 从项目自己的组学、扰动、互作或调控证据中选择最低充分的验证链。**边界：**不把固定 A-B-C-D、固定 rescue 或机制层数当作所有研究的模板。
- [`causality-rescue`](./skills/causality-rescue/) — **校准你的因果 claim。** 区分相关、必要、充分、中介与直接作用，并设计相称的扰动、回补或时间顺序证据。**边界：**rescue 是强设计之一，不是所有课题的统一硬门槛。
- [`pre-experiment-design`](./skills/pre-experiment-design/) — **用最小预实验更早做 go / no-go。** 先消除最关键风险，再决定候选、方法或主线是否值得继续投入。**边界：**不替代实验平台 SOP，也不追求固定“完成百分比”。

### ③ 材料、论文与答辩

- [`grant-and-opening`](./skills/grant-and-opening/) — **把已经形成的科学主线组织成开题、标书或科研计划。** 串起问题、创新窗口、前期证据、目标、路线、可行性与风险。**边界：**具体制度与格式必须以当前官方要求为准。
- [`sci-writing-and-revision`](./skills/sci-writing-and-revision/) — **把结果组织成论文主线与 Figure 证据顺序。** 也用于普通 SCI 稿件修改、审稿意见、回复信和 cover letter。**边界：**不把固定图数或固定补实验强度当作期刊规则。
- [`review-writing`](./skills/review-writing/) — **搭综述框架、凝练观点、组织段落论证。** 还能帮助从综述中识别未解决问题，并按影响排序停止修改。**边界：**叙事综述写作不等于系统综述方法学。
- [`thesis-and-defense`](./skills/thesis-and-defense/) — **组织学位论文、答辩和外审准备。** 帮你围绕真实工作形成学位叙事。**边界：**盲审、格式、字数、延期等规则必须查当前学校/院系官方文件。

### ④ 资源投入与收口

- [`research-mindset`](./skills/research-mindset/) — **在做不出、被抢发、结果矛盾或资源有限时决定怎么继续。** 把焦虑转成继续、收缩、暂停、转向或停止的可判断选择。**边界：**它不替代候选解释、GAP 审计或具体实验事实判断。

## 有限预算：先做会改变结论的事

这套方法默认把时间、样本、经费和注意力都当作有限资源。

当你问“还要不要再补一点”“还有没有问题”“能不能继续优化”时，优先按下面的顺序处理：

1. **会改变核心结论或课题去留的问题** — 先做。
2. **会改变关键方法、证据强度或可解释性的问题** — 视目标与成本决定。
3. **会明显影响投稿/开题/答辩交付的问题** — 在真实要求下处理。
4. **只让结果更漂亮、更完整，但不会改变判断的问题** — 降低优先级。
5. **继续投入已经没有明显信息增量** — 明确停止本轮。

“还能改”不等于“现在应该改”。停止标准本身也是科研设计的一部分。

## 30 秒开始

把需要的 Skill 放进支持 Agent Skills 的 AI 工具。复杂问题可以直接从 `meta-research-hub` 开始：

```text
请用 meta-research-hub 帮我推进这个课题。

先判断当前最值得解决的未决问题，不要一开始给我大而全的方法清单。
对每个建议说明：
1. 这一步会产出什么；
2. 它会改变什么判断；
3. 什么结果意味着继续、收缩、转向或停止。

优先给我信息增量最高、成本最低的下一步。
如果继续优化已经不会改变主线或结论，请明确告诉我停止。
```

## 这套方法坚持什么

- **从高质量论文学习发现，不搬论文答案。** 学的是发现路径、筛选逻辑和证据升级方式。
- **科学问题和论文主线先于方法堆叠。** 方法只有在能改变判断、验证假设或加强主线时才值得做。
- **探索可以积极，结论必须诚实。** 可以追踪有意义的信号，但不制造结果、不隐藏决定性反证，也不把相关性包装成因果。
- **每一轮都要落到下一步。** 结果最好能说清：得到什么、影响什么、下一步做什么，以及什么时候该停。

## 使用边界

这是一套科研思路与方法判断 Skills，不替代真实实验、实验平台 SOP、伦理审批、临床诊疗、正式统计审查、学校/期刊/基金的当前官方规则，也不保证论文发表。

需要代码、正式数据分析、图表制作或实验执行时，请使用适合任务的专业工具；这套 Skills 的作用，是让这些工具围绕正确的问题、证据和主线展开。
