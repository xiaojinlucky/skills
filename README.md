## 研究生使用 AI 科研时的真实困境

把课题输入给大模型之后，最常见的结果是得到一长段看起来很有道理的文字。文献列全了，分析方法也列满了，明天到达实验室到底先做什么，依然不清楚。

科研判断还不稳的研究生，难以识别模型是否把相关性写成了因果关系，也难以识别回答是否把别人的文献结论当成了自己课题的既成事实。对 AI 工具不够熟悉的人，容易将模型当成不会犯错的导师，或者不知道如何把真实的科研阻碍准确表达出来。这两层困扰叠加在一起，模型文字生成能力越强，研究者越容易偏离核心主线。

在生物医学和生物信息学方向，这种困扰尤为突出。文献背景、组学数据、差异基因与实验候选分子同时呈现在眼前，分析一旦陷入细枝末节，最初需要回答的科学问题反而变得模糊。

## 这套工作流为什么强大

这套工作流把从科研入门、文献研读、课题定题，到开题论证、假说验证、论文写作与答辩毕业的完整判断逻辑，写成 1 个总入口与 13 个专业 Skills。配置到 Agent 之后，它会先锁定当前最值得回答的科学问题，再将具体任务交给匹配的专业 Skill，明确当前判断、下一步产出与停止条件。

这套工作流的强大之处，在于它规范了 AI 辅助科研中最容易失控的判断次序。研究生不需要先成为所有分析方法的专家，也不需要花费大量时间钻研复杂的 Prompt 技巧。只要把课题现状与阻碍讲清楚，Agent 就会依照严谨的科学逻辑逐步剖析。

遇到复杂综合问题，从 [`meta-research-hub`](./skills/meta-research-hub/) 开始。当某个研究环节的目标已经非常明确时，也可以随时启用对应的专业 Skill。

## 每次对话拿到的四项明确结果

启用总入口并说明当前科研阻碍之后，每次对话都会得到四项明确内容。

- 当前最值得优先回答的科学问题
- 已有证据能够支持什么，关键缺口在哪里
- 下一步的具体工作，以及完成时应当获得的产出
- 不同实验或分析结果对应的处理方案，包括继续、调整、缩小目标、转向或者停止

得到这四项输出，AI 输出的就不再是一段泛泛而谈的文字，而是清晰可执行的行动方案。

## 总入口的工作方式

`meta-research-hub` 是整个工作流的总入口。你可以说明课题当前进展到哪一步，手里拥有哪些实验数据或分析结果，面临什么具体阻碍。时间周期、样本数量与算力资源等现实限制也可以一并写明。

它会先定位当前阶段最需要解决的核心问题，再从 13 个专业 Skills 中匹配合适的研究思路。每次给出的建议都会写明预期产出、该产出如何影响后续判断、下一步具体操作以及继续或停止的检验条件。

面对一批文献时，总入口会调用 [`literature-mining`](./skills/literature-mining/) 进行横向比对，核查不同命名的方法在输入、操作与输出上是否功能等价。随后对核心文献展开纵向剖析，把图表、正文、图注与实验方法还原为清晰的发现主线。在逐篇核实筛选规则、输出语义与适用语境之前，不会轻易下定论。

最终梳理出来的是一张标明证据状态的研究方向图谱。图谱中的关系明确区分为观察发现、方法使用、初步支持、参考线索或尚待验证，不会把文献结论强行拼凑成当前课题的答案。当需要将图谱结论应用到自己的课题时，由 [`topic-convergence`](./skills/topic-convergence/) 结合自身数据与资源，筛选出一个值得优先验证的问题，制定最小验证方案。

在这套工作流中，几条核心科研判断准则始终保持一致。文献用于学习科学问题如何被发现、证据如何逐步建立，并划定已知的科学边界。课题自身的假设与结论，必须由课题自身的数据和实验来支撑。分析方法服务于科学问题与论文主线，优先选用主流期刊中成熟、审稿人认可且适配当前数据的方案。有限的科研资源优先投入到能够改变核心判断的关键工作上。

## 13 个专业 Skills

面对综合科研问题，建议从 [`meta-research-hub`](./skills/meta-research-hub/) 开始。当研究任务已经具体明确时，可随时调用对应的专业 Skill。

### 发现与定题

- [`research-entry`](./skills/research-entry/) 适合研一博一或科研新手，理出第一阶段切实可行的学习与探索路径。
- [`literature-mining`](./skills/literature-mining/) 研读高质量文献，学习问题如何被发现、证据如何建立，横向比对方法等价性，剖析单篇主线，整理标明证据状态的方向图谱，寻找可靠 GAP。
- [`topic-convergence`](./skills/topic-convergence/) 将宽泛的研究方向、多组候选分子或相互矛盾的初步结果，聚焦凝练为具体可验证的科学问题。
- [`innovation-judgment`](./skills/innovation-judgment/) 核对已知研究边界与实质重合度，评估创新空间，给出深化研究或调整方向的明确依据。

### 假说与验证

- [`hypothesis-construction`](./skills/hypothesis-construction/) 将初步观察与关联现象转化为可证伪的科学假说，列出竞争性解释与判别性预测。
- [`mechanism-design`](./skills/mechanism-design/) 在表型或候选分子明确后，设计能够区分竞争性假说的分子机制验证方案。
- [`causality-rescue`](./skills/causality-rescue/) 校准结论中的因果表述强度，严格区分相关性、必要性、充分性、中介效应与独立效应。
- [`pre-experiment-design`](./skills/pre-experiment-design/) 设计低成本、小规模的预实验方案，尽早判断候选分子或技术路线是否值得继续投入，明确继续、调整或放弃的信号。

### 写作与交付

- [`grant-and-opening`](./skills/grant-and-opening/) 将科学问题与前期证据整理为严谨的开题报告或基金标书，明确研究目标、技术路线与风险预案。
- [`sci-writing-and-revision`](./skills/sci-writing-and-revision/) 梳理 SCI 论文主线与 Figure 图表的证据次序，优化正文逻辑结构，组织审稿意见回复。
- [`review-writing`](./skills/review-writing/) 搭建高水平综述框架，清晰区分前人文献结论、本文综合观点与未来待解问题。
- [`thesis-and-defense`](./skills/thesis-and-defense/) 围绕真实研究工作，整理学位论文篇章架构、盲审评阅要点与毕业答辩汇报内容。

### 投入与停止

- [`research-mindset`](./skills/research-mindset/) 面对矛盾数据、长期停滞或有限科研资源，明确精力投入优先级，制定清晰的止损与停止标准。

## 安装方法

将本仓库完整安装到当前 Agent 环境。

```bash
npx skills add https://github.com/xiaojinlucky/skills
```

也可以将仓库地址 `https://github.com/xiaojinlucky/skills` 告知支持该规范的 Agent。安装后首先启用 `meta-research-hub`，再根据课题需要调用相应的专业 Skill。本套工具是一套规范科研思路的指令体系，无需额外环境配置。文献检索、数据分析、湿实验操作与论文排版仍由对应的专业工具完成。

## 30 秒提问模板

启用 `meta-research-hub` 后，明确说明你的课题现状与困惑即可。也可以复制下方模板，花大约 30 秒填入核心信息。

```text
请用 meta-research-hub 协助我把当前停滞的课题整理成可执行的下一步。

【课题背景与当前阶段】
[在这里补充]

【已有证据与已完成工作】
[在这里补充]

【当前遇到的核心阻碍】
[在这里补充]

【时间周期、样本数量、数据规模与算力限制】
[在这里补充]

特别说明：只提供公开或已脱敏材料。未发表数据、原始测序文件与个人隐私信息请勿上传。

请优先给出以下四项内容：
1. 当前最值得优先回答的科学问题
2. 已有证据支持什么，关键缺口在哪里
3. 下一步具体做什么，完成后预期获得什么产出，该产出改变什么判断
4. 出现不同结果时，分别对应继续、调整、缩小目标、转向还是停止

文献请优先用于寻找真实 GAP，学习问题如何被发现与证据如何建立。
分析方法请优先选用主流文献常见、审稿人认可且适配当前数据的方案。
区分探索性分析与确认性证据，不人为修饰信号，也不回避关键反证。
```

<summary><strong>三个常见科研场景对话模板</strong></summary>

### 场景一 从文献中寻找真实 GAP

```text
我目前有一个大致的研究方向，但尚未确定具体的研究课题。
请协助我剖析高质量文献中科学问题是如何被发现的，证据是如何逐步建立并留下未解之处的。
请结合我的方向寻找可以检验的候选问题，不要把文献已有结论直接作为我课题的研究答案。
```

### 场景二 分析结果相互矛盾或不显著

```text
我的不同生信分析流程得到了相反方向的结果，或者初步实验结果未达到预期。
请先评估哪一个疑点最可能影响课题核心主线，并给出最值得优先复核的一项分析或实验。
如果需要调整参数或算法，请明确说明该调整属于探索性分析还是确认性证据。
```

### 场景三 论文修改不知道何时可以停止

```text
我的核心实验与生信分析已经基本完成，但论文还在反复修改，不确定是否需要继续补充实验。
请先梳理核心 claim 与 Figure 的证据次序，评估各项潜在补充工作对核心结论的影响程度。
请明确区分哪些工作会实质性改变结论，哪些工作仅增加修饰细节，并给出可以定稿停止的标准。
```
