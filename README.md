## 先把问题说清楚

`meta-research-hub` 是总入口。你只要说明课题进到哪一步、手里有哪些证据、现在难在哪里，以及时间和资源有什么限制。你不用先整理成完整方案。

它会先判断当前处在哪个阶段，再从 13 个核心 Skills 中找出适合当前问题的方法，并告诉你先做什么。每项建议都会回答一个具体问题，方便你决定继续、补证、转向或停下。

## 你会得到什么

- 当前最需要回答的问题
- 支撑判断的证据和缺口
- 下一项行动以及完成信号
- 不同结果对应的继续、缩小目标、转向或停止条件

> **发现问题 → 用文献找到 GAP → 把课题范围缩小 → 写出假设 → 设计分析或预实验 → 理清论文主线 → 按证据决定投入**

## 13 个核心 Skills

复杂问题从 [`meta-research-hub`](./skills/meta-research-hub/) 开始。问题已经明确时，可以去用对应的专业 Skill。

### 发现与定题

- [`research-entry`](./skills/research-entry/) 适合刚开始做科研，帮助你区分问题、观察和证据，并确定第一段可执行的学习路径。
- [`literature-mining`](./skills/literature-mining/) 从高质量论文中重建问题怎样被发现、证据怎样一步步建立，并寻找可核验的 GAP。
- [`topic-convergence`](./skills/topic-convergence/) 把宽泛方向、候选或矛盾结果缩小成具体科学问题。
- [`innovation-judgment`](./skills/innovation-judgment/) 核对具体课题的已知边界、实质重合和创新空间，帮助判断是否继续或调整方向。

### 假设与验证

- [`hypothesis-construction`](./skills/hypothesis-construction/) 把观察和候选关系写成可证伪假设，列出竞争解释与判别预测。
- [`mechanism-design`](./skills/mechanism-design/) 在表型或已有明确候选出现后，设计能区分竞争解释的机制验证方案。
- [`causality-rescue`](./skills/causality-rescue/) 校准相关、必要、充分、中介和直接作用等因果 claim 的表达强度。
- [`pre-experiment-design`](./skills/pre-experiment-design/) 用规模可控的预实验尽早判断是否值得继续投入。

### 写作与交付

- [`grant-and-opening`](./skills/grant-and-opening/) 把科学问题、前期证据、目标和风险写成开题或标书方案。
- [`sci-writing-and-revision`](./skills/sci-writing-and-revision/) 理清论文主线、Figure 怎么排、正文结构和审稿回复。
- [`review-writing`](./skills/review-writing/) 搭建综述框架，区分文献结论、作者综合和待验证问题。
- [`thesis-and-defense`](./skills/thesis-and-defense/) 围绕真实研究工作整理学位论文、外审和答辩材料。

### 投入与停止

- [`research-mindset`](./skills/research-mindset/) 在结果矛盾、资源有限或课题需要转向时，重新评估下一步。

## 30 秒开始

先安装 `meta-research-hub`，再按问题需要安装专业 Skill。把你的课题和难题说清楚，也可以复制下面这段再补充信息。

```text
请用 meta-research-hub 协助我继续做这个课题。

这是我的研究阶段、已有证据、资源限制和当前难题
[在这里补充]

请先判断当前最需要解决的问题，再告诉我下一步。
请分别说明三点
1. 这一步会带来什么新信息
2. 哪个判断会因此改变
3. 不同结果分别对应怎样的行动

优先安排成本可控、能改变判断的工作。
如果当前证据已经足够支撑目标，请指出可以停止补充的地方。
```

<summary><strong>三个常见场景怎么问</strong></summary>

### 从文献找 GAP

```text
我有一个大方向，但还没有具体课题。
请先重建高质量论文中的问题怎样被发现、怎样一步步建立证据和留下未解之处，
再结合我的方向寻找可以核验的候选问题。
```

### 结果互相矛盾

```text
我的不同分析得到了相反方向的结果。
请区分技术因素、背景差异和生物学解释，
再给出最值得先做的一项复核。
```

### 论文不知道什么时候该停

```text
我的主要结果已经齐全。
请先整理核心 claim 和 Figure 怎么排，
再按对结论的影响决定补充工作先后。
请说明哪些补充会改变结论，哪些只会增加细节。
```

## 方法原则

- **先从自己的问题和证据出发。** 文献用于理解问题怎样被发现、证据怎样一步步建立，并划定已知边界。项目自己的候选和结论需要自己的证据支撑。
- **科学问题决定先做什么。** 只有会改变判断、验证假设或让论文主线更清楚的工作，才值得优先投入。
- **探索可以积极，结论需要和证据相称。** 不制造结果，不隐藏决定性反证，也不把相关性写成因果。
- **有限预算先投入能改变路线的工作。** 每一项工作都应有完成信号，也应有可以停下来的条件。

## 使用边界

这套 Skills 用来整理科研问题、证据与下一步。它不能代替真实实验、实验平台 SOP、伦理审批、临床诊疗、正式统计审查，也不能保证论文发表。

涉及代码、正式数据分析、图表制作或实验执行时，请使用相应的专业工具。本系列负责让这些工作围绕清楚的问题展开。
