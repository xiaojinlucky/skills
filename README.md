## 这是什么

`meta-research-hub` 是这套 Skills 的总入口。你只需要说出现在卡住的地方，它会先判断当前最值得解决的未决问题，再组织真正有帮助的科研方法。

这套系列适合把它当作科研工作的默认思路流，而不只是某个特定软件的命令入口。课题还很模糊时，它帮你找到起点；已有数据时，它帮你从结果中发现问题；论文和综述快写完时，它帮你按影响排序并知道什么时候停止。

## 你能用它解决什么

| 你现在的状态 | 它帮你推进到哪里 |
| --- | --- |
| 方向太大，不知道从哪一刀切下去 | 从文献的发现路径和自己的证据中找到可判断的课题问题 |
| 候选很多，结果互相矛盾 | 区分技术原因、真实生物学窗口和仍需收敛的科学问题 |
| 有了结果，却不知道能不能讲成主线 | 把观察、假设、机制、因果和验证顺序分开 |
| 分析方法选择困难 | 让方法服务核心科学问题、论文叙事和可发表性 |
| 论文或综述改了很多遍 | 只保留会改变主线、证据边界或交付质量的修改，并设置停止标准 |
| 课题被抢发、实验受阻或投入失控 | 把事实审计和继续/收缩/暂停/停止决策分开处理 |

## 一条清楚的科研推进路径

```text
当前卡点
   ↓
最先要解决的未决问题
   ↓
已知 / 未知 / 证据边界
   ↓
最小但有信息增益的动作
   ↓
产出 · 影响 · 下一步
   ↓
达到停止标准，收束并继续推进
```

重点不是一次调用多少方法，而是每个方法都必须拥有一个会改变主线、核心内容、方法或下一行动的独立问题。

## 30 秒开始

把所需 Skill 放入支持 Agent Skills 的 AI 宿主，然后直接描述你现在的真实情况。默认从总入口开始：

```text
请用 meta-research-hub 作为我的科研思路流。
先判断我当前最先需要解决的未决问题，再只组织真正相关的专业方法。
请把结果按「产出—影响—下一步」收束，不要一开始给我大而全的方案。
```

也可以直接从具体卡点开始：

```text
我有一个候选基因，单细胞结果和预后方向相反。
请先帮我解释和复核这个矛盾，再判断候选如何收敛，不要为了得到一致结论直接换方向。
```

```text
我的具体课题刚被一篇新论文覆盖。
请先做实质重合、GAP 和创新窗口审计，再告诉我继续、收缩、重定位还是停止。
```

```text
这篇综述的框架、主要证据和观点已经足够。
请按影响排序告诉我哪些修改还值得做，并给出明确的停止标准。
```

## 这套方法坚持什么

- 文献用来学习作者如何发现新东西、划定已知空间和寻找 GAP，不把别人的结论直接搬成你的课题答案。
- 方法选择先服务核心科学问题，再参考高质量论文中常见、审稿人熟悉且适合当前课题的方法。
- 探索阶段允许从数据中寻找有意义的阳性信号，也保留关键路径、参数和证据等级，区分探索性发现与确认性结论。
- 先处理会改变核心结论、主线、关键方法或交付的事项；没有高影响问题时，停止继续消耗。
- 情绪可以被看见，但不会代替判断。每次支持都要落到资源、证据、行动和出口。

## 使用边界

这是一套科研思路指导系统，不替代真实实验、伦理审批、临床诊疗、统计审查或导师的最终决定。它不会编造文献、数据、实验结果，也不会保证论文发表。

正式分析、代码、图表和实验执行仍应使用适合该任务的专业工具；本系列负责让这些动作围绕正确的问题展开。

## 给研究生的一个入口

你不需要先把问题说得很完整。可以从一句真实的卡点开始：

> 我现在最担心的是……

这套 Skills 要做的，是把这句话变成一个可以判断、可以行动、也可以在适当时候停下来的科研下一步。

视觉采用 `lieflat-charts` 的 `palm / 椰林绿` 单一色系，使用暖纸灰、深棕、低饱和绿黄和琥珀色来区分路径与重点。头像保留为账号识别，README 只呈现对使用者有帮助的内容。

如果你发现某个路由不合适，欢迎在仓库中提交一个具体场景和你期待的下一步。
