# Sci Mentor 项目简报

## 要解决的问题

中文生信和生物医学科研用户经常能够看懂论文中的方法与结果，却难以回答以下问题。

- 这篇论文真正解决了什么科学问题
- 作者为什么选择这个细胞、分子或机制
- 每一组结果为什么会引出下一步实验
- 论文中的科研思路如何迁移到自己的课题
- 已有零散结果怎样组织成可验证的主线

Sci Mentor 的任务是把文献阅读、科研思维训练和个人课题推进连接成一条连续工作流。

## 产品定位

### 表层

讲清论文的科学问题、整体研究框架、关键 Figure、证据链和结论边界。

### 深层

还原作者如何从背景与前期数据形成问题，如何缩小候选范围，如何提出假设，以及如何用实验连接相邻逻辑环节。

### 最终目标

把可迁移的研究动作映射到用户自己的研究对象、数据、模型、实验条件和当前证据断点，帮助用户决定下一步。

运行结构保持轻量。

- 一个主 Skill
- 三个任务入口
- 少量按任务调用的方法单元
- Markdown 与 JSONL 证据资产
- SQLite FTS 和确定性脚本作为本机可选检索
- 不使用向量数据库、知识图谱和复杂多 Agent 运行框架

## 内容、任务和证据

### 内容层

记录科研问题、表型、机制、研究对象选择、实验分组、逻辑推进、创新性、证据边界和写作表达。

### 任务层

围绕文献解读、找课题思路和梳理课题结果组织调用。

### 证据层

区分可靠文本、未经逐字校正的 OCR、未经回听的 ASR、待处理材料和排除材料。来源类型只承担追溯与质量控制。

## 明确非目标

- 不冒充 BioAdvance 本人
- 不做人格、经历和口头禅复刻
- 不把创作者材料当作科学事实
- 不从零训练模型或做 LoRA
- 不先建设复杂 Agent 系统
- 不承诺期刊档次
- 不以增加术语、工具和流程复杂度表现专业性
