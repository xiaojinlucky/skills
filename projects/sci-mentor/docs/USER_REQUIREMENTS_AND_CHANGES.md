## 初始目标

用户希望蒸馏「做科研的大师兄」的科研思维和写作方法，形成一个面向中文科研与生信用户的 Skill，覆盖读文献、找课题思路和梳理课题结果。

工具选择遵循以下优先级。

1. 复用成熟开源社区工具
2. 借鉴小范围高质量开源工具
3. 最后才自行实现

## 用户明确排除或降级的方向

- `shixiong_writer_v1_kit.zip` 只是早期写作草案，不能直接投入使用
- `bio-tutor` 的写作评估体系与本项目无关
- `cc-kaiti` 相关材料全部排除
- 不先做重型 Agent、向量数据库、知识图谱和微调
- 不把来源类别作为项目的主要知识分类
- 不做 BioAdvance 人格扮演

## 借鉴过的本地 Skill

### meta-sci-init

借鉴课题开题的阶段结构和主线映射。具体科研方法仍需回到 BioAdvance 原始材料，不能把参照 Skill 当作一手证据。

### 同事 Skill

借鉴有证据的工作方法提取、增量更新、重复忽略、矛盾保留和用户纠错补丁。不引入职场人格层。

### 女娲 Skill

借鉴本地材料优先、跨场景复现、生成能力和非通用性筛选。不照搬人物身份卡和全网人格调研。

### 仓颉 Skill

借鉴全局理解、框架、原则、案例、反例和术语等提取视角，以及来源、解释、触发、执行和边界组成的可调用知识单元。

## 基础版带来的读文献结构

当前读文献模式已经吸收以下方法。

1. 先给出整篇论文的研究框架
2. 列出主 Figure 的核心结果、实验和分组
3. 判断 Figure 之间是平行还是递进
4. 解释每一步为什么做、做了什么、得到什么和能够推出什么
5. 追问作者为什么选择关键对象
6. 区分论文叙事顺序与可能的真实研究顺序
7. 在主线讲清后检查矛盾和证据边界
8. 最终回到用户自己的课题
