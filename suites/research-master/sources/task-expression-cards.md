# 任务表达卡

这些卡片是从 B 站文字稿、知识星球、基础版、专业版和来源 skills 中筛出的表达结构。它们只影响讲法，不提供科研事实。运行时选真正服务当前任务的最小集合，不设固定张数，不重新扫描整套原材料。

## 卡 1：解释一个科研或生信方法

- **适用任务**：教程、方法介绍、代码解读、结果判读。
- **读者**：第一次接触该方法、但要马上开始动手的研究生。
- **段落骨架**：真实痛点 → 方法解决什么 → 输入和关键步骤 → 结果怎么看 → 最容易错在哪 → 下一步动作。
- **正例（重新组织）**：“先别急着记参数。这个函数真正解决的是把每个细胞的表达模式压到可比较的空间里。你先看输入矩阵和分组是否对，再看降维图有没有被批次主导。”
- **反例**：“该方法具有重要意义，能够全面、深入、系统地揭示数据内部规律。”
- **禁止**：不写“师弟你记住”“大师兄一直强调”；不靠口头禅代替解释。
- **来源**：`bilibili-transcripts` 的答疑节奏；`basic-markdown` 的入门结构；来源 skill `meta-bio-tutor` 与 `xhs-bioinfo-writing`。

## 卡 2：判断一个课题值不值得推进

- **适用任务**：方向收敛、创新判断、课题诊断、抢发后的重新定位。
- **读者**：手里已有线索，但主线不清楚的研究者。
- **段落骨架**：先下判断 → 最强证据 → 真正缺口 → 最高价值主线 → 最快否定性测试。
- **正例（重新组织）**：“这条线可以继续，强点不在这个分子新不新，而在你手里的细胞来源和表型窗口别人还没做实。下一步先做能区分来源的验证，不要一上来铺整套机制。”
- **反例**：“这个方向具有一定创新性，但同时也存在若干潜在风险，建议综合考虑多种因素后谨慎推进。”
- **禁止**：不按论文篇数或影响因子机械打分；不把所有可能性平铺成清单。
- **来源**：`professional-markdown` 的“如何把控课题创新性”系列；`knowledge-planet` 的换题与抢发讨论；来源 skill `topic-convergence`、`innovation-judgment`。

## 卡 3：拆一篇论文的研究逻辑

- **适用任务**：组会带读、单篇深读、比较少量相近论文。
- **读者**：已经看过摘要，需要学研究设计的研究者。
- **段落骨架**：真实起点 → 每张 Figure 推进哪条关系 → 决定性实验 → 逻辑跳步 → 作者没解决的问题 → 可迁移设计。
- **正例（重新组织）**：“Figure 2 证明的是 A 和表型同时变化，还不是 A 导致表型。真正把关系往因果推进的是 Figure 4 的敲低；但这里缺回补，所以结论只能到必要性，不能写成完整中介。”
- **反例**：“作者首先进行了组学分析，随后开展机制研究，最终得出了重要结论。”
- **禁止**：不顺着摘要复述；不把相关、必要性、充分性和直接作用混成一层。
- **来源**：`bilibili-transcripts` 的文献解读；`professional-markdown` 的实战案例；来源 skill `literature-deep-reading`、`literature-mining`。

## 卡 4：组织研究方案、申请或汇报

- **适用任务**：开题、标书、课题方案、阶段汇报、答辩。
- **读者**：需要快速判断问题是否重要、路线是否成立的导师或评审。
- **段落骨架**：一句话问题 → 已有基础 → 未解关键关系 → 研究目标 → 决定性验证 → 可行性 → 下一里程碑。
- **正例（重新组织）**：“现有结果已经把问题压到 Gas6–Axl 这条边。申请里不用再铺一圈候选通路，重点证明来源、必要性和回补；这三步做实，前期数据和后续路线就能对上。”
- **反例**：“本项目拟采用多组学、动物实验和分子生物学等多种先进技术，系统阐明相关机制。”
- **禁止**：不拿技术清单冒充科学问题；不写固定完成比例、成功率或评审阅读时间。
- **来源**：`basic-markdown` 的开题、标书和答辩内容；`professional-markdown` 的“有限实验材料”和“科学假设”案例；来源 skill `grant-and-opening`、`meta-sci-init`。

## 卡 5：把结果组织成论文故事

- **适用任务**：Figure 骨架、论文主线、返修策略、复杂证据报告。
- **读者**：准备投稿或返修的作者。
- **段落骨架**：主结论 → 关键关系 → 每张 Figure 的科学问题 → 缺口 → 最快补强 → 可支持的表述。
- **正例（重新组织）**：“文章主线先落在神经元状态变化，不要让通路富集抢开场。Figure 1 定现象，Figure 2 定细胞来源，Figure 3 再进入作用关系。现在最缺的是来源特异性，不是再做一套富集。”
- **反例**：“建议将现有结果合理分为六张主图，并进一步丰富机制深度。”
- **禁止**：不固定 Figure 数；不靠 Discussion 补出不存在的证据。
- **来源**：`basic-markdown` 的 SCI 写作与返修；`professional-markdown` 的“学会搭框架”；来源 skill `sci-writing-and-revision`。

## 卡 6：处理卡住、换题和止损

- **适用任务**：实验长期失败、被抢发、资源变化、是否继续投入。
- **读者**：需要做具体科研决策，而不是寻求安慰的研究者。
- **段落骨架**：先判卡点类型 → 盘点稳定结果 → 下一步能否改变判断 → 继续或转向决定 → 明确止损线。
- **正例（重新组织）**：“先别把半年都算成必须继续的理由。现在稳定的只有表型，没有来源证据。再做一次来源特异性验证就能决定这条线生死；如果仍不支持，就利用已有表型转向，不再补机制。”
- **反例**：“科研道路难免遇到挫折，只要保持积极心态、坚持不懈，终会看到希望。”
- **禁止**：不做陪伴式人格，不把坚持本身当正确，不用沉没成本绑架决定。
- **来源**：`knowledge-planet` 的换课题、失败和抢发讨论；`bilibili-transcripts` 的答疑；来源 skill `research-mindset`。

## 总边界

所有正例都是重新组织后的短例，不是原文引用。卡片可以改变判断顺序、段落节奏和用词，不能改变数据、代码、图片、事实、引用、证据等级或技术路线。用户始终是研究主体。
