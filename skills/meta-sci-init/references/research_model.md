# 科研万能模型 · 一个中心，三个基本点

> 本模型来源：微信公众号文章《方法论 || 万能模型，搞定科研！九年科研经验浓缩》（作者：做科研的大师兄）。
> 这里将其提炼为 meta-sci-init 的方法论内核，用于**构建科学假设**并贯穿开题全程。

## 一、模型总纲

**一句话：一个中心 + 三个基本点。**

- **一个中心 = 以科学假设为中心。** 做科研最关键也最难的就是构建清晰合理的科学假设；
  科学假设一旦成型，一个课题就完成了约 80%。此后所有工作（开题报告、课题设计、
  实验计划、SCI 写作、标书写作）都**围绕这一个科学假设展开**。
- **三个基本点 = 文献推理 + 数据分析 + 实验验证。** 三个维度**统一起来**共同支撑同一个
  科学假设，缺一不可。

**科学假设 = 现象（表型） + 机制。**
用 **A–B–C–D 模型**表达：
- `A 影响 D` 是**表型**（观察到的现象）；
- `A 通过 B 调控 C 再影响 D`，中间的 **B、C 就是机制**。
- 研究生课题不必都这么复杂，可简化为 `A–D` 或 `A–B–D`，套用方式相同。

**连线约定（贯穿全模型）：**
- **虚线** = 由文献推理或数据相关性得到的**潜在/待证**关系；
- **实线** = 已被实验**直接证实**的因果关系。
- 科研的推进过程，本质就是**把虚线逐条变成实线**。

## 二、套用流程

### 第 0 步 · 确定研究主题（大方向）
一般由**导师指定**，或在**课题组研究方向**内自我限定。
例：导师让做「肺癌肿瘤免疫」→ 主题即肺癌肿瘤免疫；导师不指定 → 在课题组方向
（如「肺癌 + 非编码 RNA」）里自定。主题确定后，才开始套模型建假设。

### 第 1 步 · 文献推理 → 提出逻辑假设（三个基本点之一）
主题已定、但**子方向未定**时，用文献推理搭起子方向的逻辑关系。
- 做法：广泛阅读，归纳 A 的若干特征、D 的若干特征；
- 找**逻辑交集**：如 A 的某特征关乎「炎症」、D 的某特征关乎「免疫」，而炎症与免疫在
  基础知识上逻辑重合 → 由此推断 **A 可能与 D 相关**。
- 产出：`A┈┈D`（**虚线**，仅为可能的逻辑关系，待实验证实）。

### 第 2 步 · 数据分析 → 支持性证据（三个基本点之二）
挖掘并分析**公共数据**（结合文献），为假设提供支持，主要做**相关性分析**。
- 做法：在 D（如肺癌）与对照中，分析 B（如某非编码 RNA）与 C（如某蛋白）的水平；
  发现两者在 D 中均升高且**正相关**；再查文献发现「B 曾被报道调控 C」；
- 综合数据 + 文献 → 提出 **B 通过 C 影响 D**。
- 产出：`B┈▸C┈▸D`（**虚线箭头**，相关性证据而非直接证据，是下一步实验要证实的地方）。

### 第 3 步 · 实验验证 → 因果确证（三个基本点之三，即预实验）
针对前两步假设，提供**更直接的因果证据**，这就是「预实验做什么」的答案。
- **确证表型**：扰动自变量 A（如让 A 增多），观察 D 是否随之改变；若 A 变 D 变，
  则 A 处于 D 的逻辑上游 → `A→D` 虚线**变实线**。
- **挖掘机制**：将扰动 A 后的样本送**组学分析**（测序 / 质谱等）作为机制切入口；
  组学会给出很多被改变的对象，此时**回到第 2 步**（数据分析 + 查文献）去筛选：
  如扰动 A 后组学显示 B 升高（A 在 B 上游），叠加已建立的 `B–C–D` 逻辑，
  最终拼出完整的 **A→B→C→D** 上下游关系。

### 第 4 步 · 模块拼合
把三步得到的三个模块像**拼积木**一样合起来，得到一个**同时包含表型与机制的科学假设**。
此后所有工作都**以这个科学假设为中心**推进。

## 三、适用范围与护栏（重要）

- 模型主张**适用于大多数专业**，但其本质是**因果/机制驱动**的假设检验研究，
  在**生物、医学、药学、材料、化学、心理、农学**等实证方向最贴合。
- 对**工程/系统/设计、理论/建模、探索/数据驱动、人文社科/质性**等方向，**不要硬套
  A–B–C–D 与「表型+机制」**，改用 `hypothesis_and_design.md` 的分流策略
  （设计目标+性能指标 / 命题猜想 / 探索性研究问题 / 研究问题+理论框架）。
  可借用模型的**精神**（以一个核心论断为中心，用多源证据逐条坐实「虚线」），但换掉其生物学外壳。

## 四、在 meta-sci-init 各阶段的落点

| 阶段 | 如何用这个模型 |
|---|---|
| ②文献调研 / ③选题推荐 | 用「A–D 表型是否成立、A→D 的机制是否已知」定位研究缺口；好选题往往是一条**尚未被证实的虚线** |
| ⑤假设与方案 | **主战场**：按第 0–4 步构建科学假设；**每一条待证虚线 → 一个研究目标/Aim 与对应实验** |
| ⑥写开题报告 | 全篇**以科学假设为中心**组织：研究背景引出 A–D 现象，综述指出机制空白（虚线），研究内容=把虚线变实线的实验，技术路线=三步走 |

**一句话给 AI 的操作指令**：定题后，先帮用户把课题表达成 A–(B–C)–D 结构，标出哪些是实线
（已知/已证）、哪些是虚线（本课题要证的），再用「文献推理→数据分析→实验验证」三步为每条
虚线配上证据与实验，这就是科学假设 + 课题框架 + 实验方案的一体化产出。
