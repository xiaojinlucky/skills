# 开题咨询向导 · Meta-Sci-Init (Skill)

一个可分享的 **Skill**，让 Claude Code 或 Codex 化身科研导师，通过交互对话引导研究生
完成开题，包括**背景问诊 → 联网文献调研 → 推荐 5 个选题 → 定题 → 假设与方案 → 开题报告**。答辩 PPT 是按需能力，只有用户明确要求时才生成，默认停在开题报告。

与普通脚本不同，它借助 AI 自身的**联网检索与推理能力**，文献调研和选题推荐是真实的、
针对你背景定制的，而不是固定模板。

## 用途

适合只有宽方向、初步数据或模糊想法，还没有形成研究问题和开题骨架的研究者。它把从零到一的开题过程拆成可交互的阶段，并在每个阶段留下可以继续使用的结果。

## 能力一览
- 分层问诊：专业、方向、身份（硕/博/博后）、有无选题/预实验/数据；无选题时深挖导师方向、
  实验室论文、平台层级（普通/中高/顶级）、发表需求（期刊级别）。
- 联网调研该领域近期文献、热点与研究空白（WebSearch / WebFetch）。
- 结合背景与平台层级，推荐 5 个匹配、有创新、可行的选题，含可行性与发表匹配度分析。
- 先判断核心科学问题和论文主线，再选择高质量文章中常见、审稿人熟悉且适合当前条件的方法。
- 所有输出统一执行可理解性规范，吸收 human-writing、oil-tone、anti-defensive-writing 的核心思路。重要判断必须有材料托底，每段持续增加新信息，事实与推断分开，语言平实完整，先讲判断再讲必要范围。
- 每次阶段性输出前进行一轮科研逻辑、事实边界、中文科研表达、防御性写作和可理解性自查。
- 定题后分析**前期数据与前期论文**（可读取 CSV/图片/PDF），打通「数据观察 + 文献缺口」逻辑，
  **构建科学假设**并设计**课题框架与实验方案**；实证方向优先套用内置的**「科研万能模型：
  一个中心、三个基本点」**（以科学假设为中心 + 文献推理/数据分析/实验验证），对不需要假设的
  方向（工程/理论/质性等）自动切换对应策略。
- 逐节协助撰写开题报告，导出 `开题报告.md`。
- **开题答辩 PPT 默认关闭**。完成报告后不会自动检查 PPT 能力、安装技能或生成文件。只有用户明确说「做PPT」「生成答辩PPT」「把报告做成PPT」等指令时才启动。触发后优先使用 Anthropic 官方 `pptx` 技能；不可用时再按原有降级路径生成 `开题报告PPT.pptx`。

## 工作流程
```
① 背景问诊 → ② 联网文献调研 → ③ 推荐5个选题 → ④ 定题确认
   → ⑤ 前期基础分析·科学假设·课题框架与实验方案 → ⑥ 逐节写开题报告

⑦ 按需生成开题PPT，仅在用户明确要求时触发
```

## 安装（把这个文件夹分享给别人即可）

**Claude Code 个人级安装**
把 `meta-sci-init/` 整个文件夹复制到：
- macOS / Linux：`~/.claude/skills/meta-sci-init/`
- Windows：`%USERPROFILE%\.claude\skills\meta-sci-init\`

**Claude Code 项目级安装**
复制到项目内 `.claude/skills/meta-sci-init/`，提交到 git，团队成员拉取即得。

安装后，在对话里说「我要开题」「帮我选题」或直接 `/meta-sci-init`，技能即被调用。

**Codex / 其他支持 Skills 的 Agent：**
将本文件夹放入其技能/插件目录（参考对应工具文档），核心是让 Agent 能读取 `SKILL.md`。
`SKILL.md` 是标准的带 YAML frontmatter 的 Markdown 指令文件，与工具无关。

## 用法
安装后直接对 AI 说明来意即可，例如：
> 我是材料专业硕士生，想开题但还没选题，帮我一步步来。

AI 会自动进入问诊流程，默认引导你完成前六个阶段并停在开题报告。你可随时说
`跳过` / `上一步` / `重做问诊` / `直接推荐选题` / `开始写报告` / `导出报告`。需要答辩 PPT 时，再明确说 `做PPT` 或 `生成答辩PPT`。

## 文件结构
```
meta-sci-init/
├── SKILL.md                          # 核心指令（AI 读取它来驱动全流程）
├── README.md                         # 本文件
├── references/
│   ├── proposal_structure.md         # 开题报告通用章节模板
│   ├── topic_recommendation.md       # 文献→选题的方法论与分层适配
│   ├── hypothesis_and_design.md      # 前期基础分析→科学假设→课题框架与实验方案
│   ├── research_model.md             # 科研万能模型：一个中心、三个基本点（构建假设的内核）
│   └── ppt_structure.md              # 开题 PPT 结构与排版规则
└── scripts/
    ├── build_pptx.py                 # 生成 .pptx（无 python-pptx 时降级为 Marp .md）
    └── content.example.json          # PPT 内容 JSON 示例
```

> 只有用户明确要求生成 PPT 时才会进入 PPT 流程。若走内置脚本路径，生成 `.pptx` 需要 `python-pptx`（`pip install python-pptx`）；未安装时脚本会自动降级输出 Marp 幻灯 Markdown。

## 输出规范来源

本 Skill 的全局表达规则吸收了 `KKKKhazix/human-writing`、`oil-oil/oil-tone` 和 `Kiterlin/anti-defensive-writing` 的核心方法，并按科研场景重新组织。目标不是模仿某一种个人文风，而是让对话、报告、表格和 PPT 都做到有材料依据、逻辑向前推进、事实边界清楚、表达自然直接，并让没有参与课题全过程的研究生也能第一次读懂。
