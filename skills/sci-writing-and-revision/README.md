# SCI Writing and Revision

面向普通 SCI 或一般生命科学稿件的主线、Figure 顺序、正文结构、审稿意见和回复信。

以 Nature/CNS 风格起草、正式逐条回复或完整论文流水线分别交给对应专门 Skill；任何写作都不能扩大证据支持的 claim。

输出应包含核心 claim、证据边界、叙事顺序、正文/回复修改和局部复验结果。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供结果图、稿件或审稿意见，并说明目标稿件类型和当前主张。

## 配置

无需额外配置；目标期刊的当前要求应由宿主检索并核对。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。Nature/CNS 专门写作、正式回复和完整论文流水线转交对应专门 Skill。
