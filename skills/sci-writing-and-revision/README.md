# SCI Writing and Revision

已有科研结果，需要理清论文主线、Figure 怎么排、正文结构、审稿意见和回复信时，使用这个 Skill。

## 适合什么时候用

你已经有结果图、稿件或审稿意见，希望让每个段落和 Figure 都服务于当前 claim。

## 使用时带上

结果图、稿件、审稿意见、目标稿件类型和当前主张。

## 你会得到

核心 claim、证据边界、叙事安排、正文或回复修改，以及局部复验结果。

## 使用边界

Nature 或 CNS 专门写作、正式逐条回复和完整论文流程需要相应的专门 Skill。任何写作都不能扩大证据支持的 claim。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后提供结果图、稿件或审稿意见。

## 配置与运行环境

无需额外配置；写作修改应以当前证据和目标期刊要求为准。
