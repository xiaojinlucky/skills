# 综述写作

## R  核心论点 (Reading)

综述框架来自研究问题、证据主题和现有综述的比较，不应凭空想象，也不能照抄单篇框架。先建立足以覆盖主要概念、争议和证据类型的文献池，再按当前问题分类；数量和时间跨度由主题成熟度、变化速度与停止条件决定。

综述写作有三个目的：系统学习研究方向基本概念研究方法和常识结论 + 系统构建研究领域涉及研究结论的证据关系与适用边界 + 系统总结研究领域未解决的科学问题（潜在研究方向）。

综述观点凝练三种符合逻辑的方法：总结（同类结论归纳共性）/ 推理（多篇文章结论逻辑链条推理出新观点）/ 对比（不同方向结论对比提出不确定性观点）。可以大胆提出自己的观点，但由文献综合出的每个关键观点都要标明可定位的证据来源；没有来源时只能写成“待检索观点/待验证推断”，不能写成已有研究结论或已被证实的机制。这里区分两种使用场景：用户已提供文献池、摘录或检索结果，或明确要求正式成稿时，关键事实应附作者、年份、DOI、文献编号或其它可定位来源；用户只是先理清问题和框架、没有来源输入且未要求检索时，默认停留在思路层，只标明推断性质和需要核验的证据类型，不为每条观点堆叠引用占位，也不把缺少引用当作该次回答失败。

通过综述找未解决科学问题有四种逻辑推理层次：整体观念（找更上游的共同因素，如多个因素与免疫环境改变相关；只有存在直接且可比的干预证据时，才可把共同上游的潜在干预优势作为已有结论，否则只是待检验问题）+ 研究空白（证据关系图或机制工作模型里缺掉的环节，如已有研究分别提示 PI3K 突变与 ROS 相关，但 PI3K 突变如何影响 ROS 仍未知）+ 基础转化（体外/体内机制到临床应用）+ 跨领域整合。逻辑缺口可以形成可检验的问题或文献启发的工作假设，但不能仅凭文献链确证具体机制；进入具体项目 claim 前还要补充当前数据、模型异常或预实验依据。

跨多篇、跨适用背景或不同证据层级的文献综合，只能绘制为“证据关系图”或“机制工作模型”，不能直接称为“因果关系图”。图中每条关键边都要标注其证据类型：直接干预证据、关联/共现、跨文献综合或待验证假设，并注明适用背景（如体外/体内、物种、细胞类型、疾病阶段等）与来源状态（单篇原始研究、综述/二手总结或作者综合）。只有在同一适用背景下存在与该强度相称的直接干预证据时，才使用“导致”“介导”“驱动”或“因果”等强因果表述；否则使用“相关”“伴随”“提示”“可能连接”或“工作模型”等中性表述。

综述段落需要清楚的论证关系，可通过内容顺序、指代和必要的逻辑连接表达；不要机械在每句话之间塞关联词。

AI 工具可以辅助检索、证据整理、结构比较和语言修改，但不能替代来源核查、作者判断、期刊真实要求或研究诚信。

## 综述类型边界

本 Skill 默认服务叙事性、批判性或观点型综述。系统综述、范围综述、Meta-analysis 等通常需要预先定义协议、可复现检索、纳入与排除标准、偏倚或质量评价以及适用的报告规范；本 Skill 可以协助问题和框架，但不替代这些方法学流程。

## I  方法论骨架 (Interpretation)

综述写作要解决的核心问题是，怎么从海量文献里提炼出一个有自己观点的综述框架。

综述写作有三个目的：系统学习基本概念方法+构建研究结论的证据关系+总结未解决科学问题。构建证据关系是把零散研究结论、证据层级和适用背景用“证据关系图”或“机制工作模型”可视化展示（如以 PI3K 突变、ROS、Stat3、免疫细胞和免疫环境为节点，基于多篇文献报道综合；关键边须标注证据类型与待验证假设），类似盲人摸象把每个局部汇总推断全貌。

框架构建采用迭代法：先定义综述问题和边界 → 用多查询建立代表性文献池 → 比较已有综述覆盖了什么、遗漏了什么 → 根据证据主题、争议和目标读者形成第一版框架 → 继续检索并修订，直到新增来源不再改变主要结构。已有综述用于识别结构先例和覆盖缺口，不能只换标题后复用。

观点凝练三方法：总结（同类结论归纳共性）/ 推理（多篇文章结论逻辑链条推理）/ 对比（不同方向结论对比提出不确定性）。

通过综述找未解决科学问题有四种逻辑推理层次：整体观念（找更上游的共同因素）+ 研究空白（证据关系图或机制工作模型里缺掉的环节）+ 基础转化（机制到临床应用）+ 跨领域整合。基于构建的证据关系图或机制工作模型，用合理逻辑推理提出尚未解决的科学问题。

综述修改遵循“有限预算—影响排序—停止标准”：先处理会改变当前问题、框架、证据边界或关键观点的问题，再处理影响论证清晰度和段落推进的问题，最后才处理局部措辞。每轮只修改最值得改的部分；当论证关系清楚、段落能推动当前问题且没有无效重复时停止，不为追求表面统一而无限润色。

AI 工具可以辅助综述初稿、结构整理、表图说明和投稿清单；实际投稿要求、查重和 AI 检测须由作者通过学校、期刊或相应检测服务取得真实结果并逐项核验。

## A1  典型应用案例 (Past Application)

### 案例 1：某疾病+某免疫细胞综述框架构建
- **问题**：要写某疾病+某免疫细胞的综述，不知道框架怎么定
- **方法论的使用**：确定主题和读者问题 → 比较若干真正相关的已有综述及其覆盖边界 → 从当前证据主题、争议和 GAP 形成新框架 → 按逻辑关系整合
- **结论**：已有框架提供先例和缺口，最终结构必须服务当前综述问题
- **结果**：获得可用的综述框架

### 案例 2：综述观点凝练
- **问题**：综述写完了但没有自己的观点，只是内容堆砌
- **方法论的使用**：用三方法凝练观点，总结（归纳共性）/ 推理（逻辑链条推理）/ 对比（对比提出不确定性）→ 大胆提出符合逻辑的观点
- **结论**：综述必须有自己观点，三方法确保观点符合逻辑
- **结果**：综述有了自己的观点

### 案例 3：先找文献再分类形成综述框架
- **问题**：学生想写综述但卡在第一步，不知道怎么精准检索每个框架对应的文献，无法启动
- **方法论的使用**：先用宽查询建立初始领域地图，再按证据主题分类并迭代框架；通过覆盖缺口和停止条件控制范围，不无边界收集
- **结论**：先获得真实证据再修订框架，通常比把未经验证的框架固定到底更可靠
- **结果**：学生建立了可追溯、可继续完善的综述结构

### 案例 4：通过综述证据关系图定位待验证研究问题
- **问题**：学生写综述不知道怎么通过综述找到未解决的科学问题作为课题切入点
- **方法论的使用**：通过综述找科学问题的四种逻辑推理。构建证据关系图或机制工作模型（如以 PI3K 突变、ROS、Stat3、免疫细胞和免疫环境为节点，基于多篇文献报道综合）→ 整体观念（多个因素与免疫环境改变相关，若没有直接且可比的干预证据，只把共同上游的干预优势写成待验证问题）→ 研究空白（已有研究分别提示 PI3K 突变与 ROS 相关，但 PI3K 突变如何影响 ROS 未知）→ 基础转化（体外/体内机制到临床应用）；对每条关键边标出直接干预证据、关联/共现、跨文献综合或待验证假设，并注明适用背景与来源状态，不把“可能通过代谢影响 ROS”写成已成立机制。
- **结论**：综述不只是写完就完，通过证据关系图或机制工作模型和四种逻辑推理可以找到有证据锚点的、待后续检验的科学问题
- **结果**：学生通过综述形成了具体的研究空白问题、竞争解释和后续验证方向

### 案例 5：AI 工具辅助整理综述投稿材料
- **问题**：学生想写综述投稿但效率低，写完还要整理 cover letter、表图说明和投稿清单
- **方法论的使用**：用 AI 工具辅助综述结构、初稿、表图说明和材料清单；来源、作者判断、期刊要求以及查重/AI 检测结果由作者和相应服务逐项核验。熟悉工作流可以缩短准备周期，但不能预设时限或检测结果。
- **结论**：AI 工具可以辅助提高综述写作和材料整理效率，但不能替代作者核查或外部检测服务
- **结果**：形成一套待作者核验和完善的综述投稿材料包

### 用户会在什么情境下需要这个 skill？

1. **写综述定框架**，要写综述但不知道框架怎么定

- 「怎么凝练自己的观点 / 综述观点」
- 「综述小标题怎么分 / 怎么归类」
- 「如何借鉴并重组已有综述框架 / 借鉴修改」
- 「综述写作顺序 / 先找文献还是先定框架」
- 「综述段落论证 / 句与句怎么连接」
- 「review writing / review framework / viewpoint condensation」

### 与相邻 skill 的区分

- 与 `sci-writing-and-revision` 的区别，本 skill 解决综述写作（归纳+观点），sci-writing-and-revision 解决研究性 SCI 论文写作（研究问题、结果证据与 story 重构）。
- 与 `literature-mining` 的区别，literature-mining 解决读文献找课题，本 skill 解决写综述（读是写的前置）。
- 与 `thesis-and-defense` 的区别，本 skill 解决综述，thesis-and-defense 解决毕业论文（毕业论文绪论部分会用到综述方法）。

## E  可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行。

1. **确定综述主题**
   - 完成标准：明确综述主题（如「某疾病+某免疫细胞」）

2. **建立足以回答问题的文献池**
   - 根据主题变化速度选择时间范围，用多查询和引用链覆盖主要概念、争议、方法和反证
   - 需要结构化证据时调用现有文献检索能力，不为普通综述机械生成 CSV 或 PDF
   - 完成标准：新增来源已很少改变主要主题、争议和证据边界

3. **框架提取+修改重组**
   - 比较已有综述的范围、结构和遗漏，再根据当前问题形成自己的框架
   - 完成标准：每个一级部分都回答当前综述问题中的一个必要子问题

4. **按重组小标题归类文献**
   - 每个小标题下面文献按照逻辑关系整合：时间先后、观点异同、研究递进、逻辑推理+跨类整合
   - 完成标准：文献归类完成

5. **凝练自己的观点（三方法）**
   - 总结（同类结论归纳共性）/ 推理（逻辑链条推理）/ 对比（对比提出不确定性）
   - 大胆提出符合逻辑的观点
   - 完成标准：有文献池、用户文献或检索结果并进入成稿时，每个关键观点附作者、年份、DOI、用户提供的文献编号或其它可定位来源；只有框架思路且没有来源输入时，保留 1-3 个标记为“待检索观点/待验证推断”的观点，并列出需要补的证据，不扩写成带大量引用占位的完整综述。任何场景都不伪造引用，也不把作者综合写成文献事实

6. **检查论证关系与段落推进**
   - 按影响排序检查：先修正会影响当前问题、证据边界或关键观点的论证问题，再处理段落顺序、指代和必要连接，最后处理局部措辞
   - 通过内容顺序、明确指代和必要连接共同表达并列、递进、转折、因果或总分关系；只在真实逻辑跳跃处补最少连接，不把连接词出现与否作为形式门槛
   - 每轮只处理当前最影响理解和问题推进的部分；达到完成标准后停止修改
   - 完成标准：论证关系清楚，段落能推动当前问题，没有无效重复；连接词使用适量且服务内容，不以每段都出现连接词为目标

7. **通过综述找未解决科学问题（四种逻辑推理）**
   - 整体观念（找更上游的共同因素，如多个因素与同一表型相关；只有直接且可比的干预证据支持时，才总结为干预效果更好，否则保留为待验证方向）
   - 研究空白（证据关系图或机制工作模型里缺掉的环节，如已有研究提示 A 与 B 相关，但 A 是否以及如何影响 B 未知）
   - 基础转化（体外/体内机制到临床应用）
   - 跨领域整合
   - 完成标准：通过综述形成 1-3 个未解决的科学问题或文献启发的待验证方向；每个问题注明已知证据、未知环节和至少一种替代解释，不将其表述为已成立机制或已验证课题

8. **（可选）AI 工具辅助综述写作**
   - 用 AI 工具辅助稿件初稿、cover letter 草稿、表图说明和投稿清单；不得生成、代替或承诺查重/AI 检测报告及其达标结果
   - 使用者仍需核查来源、作者判断、目标期刊规则和相应检测服务的真实结果
   - 不承诺固定完成时长或外部检测结果；完成标准：材料初稿和核验清单齐备，作者已按目标期刊与检测服务的真实要求完成核验

## 检查点与失败分支

**检查点 1（step 2 之后）**：主要概念、争议、方法、反证和近年变化是否已有来源覆盖。只补真实缺口，不按篇数判定深度。

**检查点 2（step 5 之后）**：每个主要部分是否有基于证据的综合判断，并清楚区分来源结论、作者综合和仍未解决的问题。只有文献罗列时回到 step 5 凝练。

- 如果框架提取（step 3）直接照抄某篇综述的小标题，修改重组为自己的框架，照抄框架会被审稿人判定无创新性。
- 如果检索返回结果太少，换多查询策略重检，单一查询策略容易漏掉相关文献。
- 如果通过综述找未解决科学问题（step 7）找不到切入点，用四种逻辑推理逐个试（整体观念 / 研究空白 / 基础转化 / 跨领域整合），不要只靠一种方法就放弃。

## B  边界 (Boundary) ★

### 这个 skill 服务什么课题主线

- 服务「高质量文章常用方法论」的课题主线：通过借鉴+修改框架+三方法凝练观点写综述
- 服务需要写综述的硕博生和青年临床医生

### 不要在以下情况使用此 skill

- **研究性 SCI 论文写作**：用 sci-writing-and-revision，本 skill 解决综述
- **毕业论文**：用 thesis-and-defense（毕业论文绪论部分可参考本 skill 的综述方法）
- **具体文献检索工具操作**：本 skill 解决综述写作方法，不解决 PubMed/Endnote 操作

### 常见失败模式

- **追求完全原创框架**：不从已有综述借鉴，导致下笔困难、框架混乱、耗时极长
- **内容堆砌无观点**：只归类文献不凝练观点，综述没有自己的见解
- **无限修改局部措辞**：反复润色表面表达，却没有按影响优先修复论证和段落推进问题，也没有在达到停止标准后收口
- **论证关系不清**：内容顺序、指代或必要连接不足，导致段落无法推动当前问题或出现无效重复

### 容易混淆的邻近方法论

- `sci-writing-and-revision`：研究性 SCI 论文写作（不同写作类型）
- `literature-mining`：读文献找课题（本 skill 前置）
- `thesis-and-defense`：毕业论文（绪论部分可参考本 skill）
