# Review Writing

面向叙事性、批判性或观点型综述的问题、框架、证据主题和观点凝练。

系统综述、范围综述和 Meta-analysis 通常还需要协议、可复现检索、纳排标准、质量/偏倚评价和报告规范；本 Skill 不替代这些方法学流程。

输出应区分来源结论、作者综合、未解决问题和待验证工作假设。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供综述主题、目标读者、已有文献池和想形成的观点。

## 配置

无需额外配置；文献检索使用宿主可用的学术检索能力。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。系统综述、范围综述和 Meta-analysis 需要额外的方法学流程，不由本 Skill 单独替代。
