# Thesis and Defense

面向学位论文、外审、盲审、答辩和当前学校/院系制度核对。

官方规则必须按学校、院系、学位类型和年份核实；发表论文数量不能替代送审要求和论文整体质量。

输出应包含规则来源、总论点、章节证据地图、真实阻塞项和可执行修改。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供学校、院系、学位类型、年份、论文材料或外审意见。

## 配置

无需额外配置；正式制度必须由宿主按当前官方来源核对。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。它不把发表数量、旧规则或模拟评审意见当作当前制度事实。
