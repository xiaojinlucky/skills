# Thesis and Defense

需要整理学位论文、外审、盲审或答辩材料，并核对当前学校或院系要求时，使用这个 Skill。

## 适合什么时候用

你已有论文材料或外审意见，希望把研究工作整理成清楚的总论点和章节证据地图。

## 使用时带上

学校、院系、学位类型、年份、论文材料或外审意见。

## 你会得到

规则来源、总论点、章节证据地图、真实阻塞项和可执行修改。

## 使用边界

学校、院系、学位类型和年份对应的官方规则需要重新核实。发表论文数量不能代替送审要求和论文整体质量。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后说明学校、院系、学位类型、年份和现有材料。

## 配置与运行环境

无需额外配置；学校和院系规则必须按当前官方来源核对。
