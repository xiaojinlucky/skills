# 中文生信社区推文

把已经有事实依据的生信原理、分析方法、科研判断或论文解读，改写成中文生信社区容易读懂的推文、长帖或短回复。

## 用途

负责平台表达、标题、结构、术语、节奏和配图适配，让已有内容更适合社区阅读；科学结论仍以当前项目证据为准。

## 使用

提供事实材料、目标受众、平台形态和希望保留的重点。可以指定长帖、短回复、图文笔记或标题组。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。核心入口是 `SKILL.md`。

## 配置

无需额外配置。若需要图片、代码或论文事实核验，应同时提供对应材料或调用适合的专业工具。

## 兼容性与边界

支持能加载 Markdown Skill 的 AI 宿主。本 Skill 不负责编造科学结论、运行完整生信代码或替代论文事实核验；它只做平台表达适配。
