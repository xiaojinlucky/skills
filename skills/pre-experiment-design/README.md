# Pre-experiment Design

为一个关键未知设计最低充分、具有决策价值的预实验。

组别、样本、读出和规模由问题、模型、变异、平台和资源决定，不套固定百分比、固定样本数或强制 rescue。复现任务需明确其验证性质。

输出应包含决策问题、候选证据、设计依据、成功/失败分支、样本生命周期和停止条件。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供当前关键未知、模型/样本/技术资源、预算和预实验要改变的决策。

## 配置

无需额外配置；实验设计必须服从实际平台 SOP、伦理和安全边界。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。预实验不套固定完成百分比、固定样本数或强制 rescue。
