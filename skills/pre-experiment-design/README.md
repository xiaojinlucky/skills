# Pre-experiment Design

一个关键未知需要用一轮规模可控、能够改变决定的预实验来判断时，使用这个 Skill。

## 适合什么时候用

你已经有候选或假设，需要决定先做哪项实验，以及什么结果支持继续、缩小目标或停止。

## 使用时带上

关键未知、模型或样本、技术资源、预算，以及这轮预实验要改变的决定。

## 你会得到

决策问题、设计依据、组别、样本、读出、成功与失败分支、样本使用安排和停止条件。

## 使用边界

实验设计服从实际平台 SOP、伦理和安全要求，不套固定完成百分比、固定样本数或强制 rescue。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后说明关键未知、可用模型、预算和要改变的决定。

## 配置与运行环境

无需额外配置；具体样本量和实验执行必须结合平台、伦理与资源核定。
