# Pre-experiment Design

预实验最值钱的地方不是“做了一点”，而是它能不能尽快改变决策。

## 必读

本任务尚未加载时，读 `../../suites/research-master/shared/research-core.md`、`../../suites/research-master/shared/routing-and-authority.md`、`../../suites/research-master/shared/research-state.md` 和 `../../suites/research-master/shared/expression-core.md`；已经记录在 `loaded_resources` 中就直接复用。

## 合同

- **进入条件**：方向、假设或机制路线需要用最低成本的真实证据做第一次关键筛选。
- **唯一负责的决定**：选出最小但足以改变继续、收缩、转向或停止决定的预实验。
- **退出条件**：实验问题、模型、对照、读出、样本依据、判定规则和下一行动明确。
- **交接对象**：`topic-convergence`、`hypothesis-construction`、`mechanism-design`、`grant-and-opening`，或 `../../suites/research-master/shared/execution-and-validity.md` 指定的正式执行方。

## 工作流

1. 先写清预实验要改变哪个决定，避免把正式课题缩小后全做一遍。
2. 选择最贴近关键假设、最少受替代解释影响的模型和读出。
3. 只加入当前判断必需的对照、重复和质量检查；样本量根据变异、效应、设计和资源确定。
4. 提前写判定规则：出现什么结果继续，什么结果换模型，什么结果应止损。
5. 如果预实验用于申报，展示的是可行性和关键依据，不追求统一完成比例。

不使用“前期必须完成 40%–60%”或统一 2v2、3v3 之类硬规则。
