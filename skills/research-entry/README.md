# Research Entry

面向科研新手、研一或博一学生的科研认知与第一段学习路径。

适合区分问题、观察、候选、假设、方法和证据，并形成短期可运行的小循环；已有具体课题、机制或实验设计应交给相应专业 Skill。

输出应说明当前阶段、关键缺口、第一阶段目标、少量行动和下一交接。需要的共享科研规则由宿主按需提供。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

说明你的科研阶段、已有项目背景和最困惑的概念或行动。

## 配置

无需额外配置；需要的共享科研规则由宿主按需提供。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。已有具体课题、机制或实验设计应转交相应专业 Skill。
