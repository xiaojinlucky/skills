# 科研心态与自救

本 skill 的情绪承接只是进入判断的短步骤，不是交付结果。被激活后，除非用户明确只想倾诉，否则必须把焦虑转成当前证据状态、仍未决的关键问题、最小下一步和停止或转向条件；安慰最多占很短一段，不替代科研判断。

## R  核心论点 (Reading)

**做科研智商不是决定因素**，出身不好不妄自菲薄，出身好不骄傲自大。任何人任何时间任何地点都可以创新，本科双非也能做出好科研，本科 985 也不能觉得聪明就掉以轻心。读研入学那一刻是全新开始，保持头脑清晰、目标明确、心态稳定才能拿到学位。

做课题过程中需要关注课题是否仍有创新空间，并关注实时更新的发表的文献。涉及实质重合、GAP 和创新性是否成立的事实判断，先用 `innovation-judgment` 核对；本 Skill 在已有判断基础上支持投入、情绪和转向。发现被抢发或创新性不足的信号后，先完成相应核对，再选择与证据相称的出口。换题不意味着之前的结果都不能用，基于已有结果可开辟新方向。

创新性不能用论文篇数机械量化。当前核心问题是否已在相同背景、细胞关系、方向和证据层级被完整回答，以及属于部分已知、矛盾还是 GAP，应由 `innovation-judgment` 完成事实核对；若尚未完成核对，应先完成这一步，不由本 Skill 复制查文献和判断。本 Skill 只在已有判断基础上帮助稳定情绪、评估投入和选择下一出口。

实验结果矛盾且用户主要需要解释候选、数据或科学问题时，先用 `topic-convergence` 或相应分析方法处理证据与竞争解释；若复核后形成候选窗口，再由 `innovation-judgment` 核对其 GAP 属性。本 Skill 在这些判断已有结果后，帮助稳定情绪、安排投入和选择出口。偶然阳性和矛盾信号都值得保留；探索时可以比较有记录的合理方法或参数来理解信号，并保留发现优先、探索/确认区分和真实性边界。

被抢发不等于课题废了。先由 `innovation-judgment` 比较自己的现有数据与抢发文章真正重合和不同的部分，审计剩余创新窗口；审计完成后，本 skill 再根据证据、资源和时间支持继续、收缩、重定位、转向、暂停或停止。新方向的具体问题收敛回到 `topic-convergence`。

## I  方法论骨架 (Interpretation)

科研心态与自救要解决的核心问题是，在候选和数据解释、创新性事实审计已有结论后，如何处理焦虑、投入、节奏以及继续、收缩、转向、暂停或停止。

正确看待自己：智商不是决定因素，出身不好不妄自菲薄反而要更勤奋，出身好不骄傲自大。入学那一刻是全新开始，保持头脑清晰、目标明确、心态稳定。

换题时机支持：先使用 `innovation-judgment` 对实质重合、GAP 和创新性完成事实审计；在已有判断或证据复核显示核心问题已被同层次证据完整回答且当前项目没有新的背景、阶段、细胞关系或机制窗口，或者自己的关键表型长期缺少可信证据时，本 skill 根据资源与时间支持及时转向。换题不意味着之前的结果都不能用，具体新方向回到 `topic-convergence` 收敛。

被抢发挽救策略：核心创新点被抢发后不等于课题废了。在 `innovation-judgment` 完成实质重合与剩余创新窗口审计后，本 skill 根据该结论、现有证据、资源和时间支持差异化重定位、继续、暂停或转向；新方向的具体问题回到 `topic-convergence` 收敛。

实验验证不出假设：若首要问题是判断候选、表型或背景如何解释，先用 `topic-convergence` 或相应分析方法；本 Skill 根据证据复核结果，结合时间、资源和最低交付门槛选择继续、收缩 claim、暂缓补证、转向或停止。

实验结果矛盾：若首要问题是如何解释候选、数据或科学问题，先用 `topic-convergence` 或相应分析方法；完成技术、背景和竞争解释后，本 Skill 只根据结果和有限预算选择下一出口。保留相反方向及探索/确认区分，不把情绪或“还能不能做”替代为事实判断。

科研焦虑：先用一两句承接情绪，再把问题改写成有限决策：当前要交付什么、剩余时间或资源是多少、什么结果会改变判断、达到什么标准就停止本轮。优先处理最可能影响结论、主线或交付的 3–5 个问题；没有高影响问题时明确建议停止，不把“还能改”误写成“应该继续改”。导师放羊时也按同一原则，用文献、数据和预实验建立可执行的判断，而不是只靠鼓励维持行动。

## A1  典型应用案例 (Past Application)

### 案例 1：肺纤维化+A蛋白+SPP1换题
- **问题**：A 蛋白通过 SPP1 巨噬细胞调控肺纤维化，但 A 促纤维化和 SPP1mac 促纤维化都已报道，创新性不足需换题
- **方法论的使用**：不用慌，基于已有结果（SPP1 结合 A 蛋白）开辟新课题 → 聚焦 A 如何调控 SPP1（蛋白稳定性→泛素化等）→ 落脚到 SPP1 参与的新表型
- **结论**：换题不意味着之前结果都不能用，基于已有结果可开辟新方向
- **结果**：基于已有结果开辟新课题方向

### 案例 2：胃癌+A基因+免疫评分逻辑矛盾处理
- **问题**：学生筛到 A 基因但数据逻辑矛盾（高表达预后好+免疫评分低+GSEA促进免疫）
   - **方法论的使用**：先核查分组、批次、样本组成和效应稳定性；仅当细胞来源会改变解释且有合适证据时，再回看单细胞确认主要表达细胞、用细胞内 GSEA 或其它匹配方法检查功能背景；随后保留高表达预后好等相反结果，判断是否为细胞或阶段特异现象
- **结论**：矛盾结果不能通过放宽阈值换成符合预期的基因；排除技术原因后，它可能形成值得交由 `innovation-judgment` 审计的候选窗口
- **结果**：学生区分技术冲突与潜在新生物学，再按证据选择下一出口

### 案例 3：D药-PGAM1-肝癌聚焦创新点心态调整
- **问题**：学生做 D 药-PGAM1-肝癌，前期实验重复了文献已知的东西，焦虑觉得做了无用功
- **方法论的使用**：不用慌，识别哪些是文献已知的（D 药抑制增殖/迁移/凋亡）→ 聚焦真正的创新点（D 药抑制 PGAM1 蛋白水平）→ 把已有结果作为基础，重新围绕创新点设计后续实验
- **结论**：做了无用功不慌，识别创新点后重新聚焦，已有结果不浪费
- **结果**：学生调整心态，重新聚焦可验证的创新点并形成后续证据链；期刊层级需另行评估

### 案例 4：核心创新点被抢发后的差异化重定位
- **问题**：课题快做完或正在投稿时发现核心创新点被抢发，不知道还能不能发
- **方法论的使用**：对比抢发文章和自己的课题 → 从已有数据确认仍未被回答的新背景、阶段、细胞关系、机制深度或应用窗口 → 只围绕有当前证据支持的窗口调整主线。两篇相似顶刊从不同角度报道相关发现只能说明差异窗口可能存在，不能把对方答案换一个模型后直接复刻
- **结论**：被抢发不等于课题自动终止；若找到当前证据支持且与抢发文章实质不同的窗口，可以重新评估课题价值和投稿路径，但不保证继续投稿或达到某一刊物层级
- **结果**：学生明确了被抢发后的挽救策略

### 案例 5：两篇一区SCI因盲审没过被延毕
- **问题**：学生发了两篇一区 SCI，但毕业论文盲审没过被延毕
- **方法论的使用**：了解盲审双盲机制（送审时隐藏学生和导师姓名，返回时隐藏评审人姓名）→ 盲审评价指标（选题意义、文献综述、研究方法、创新性、写作规范等）→ 提前避坑（论文格式规范、逻辑完整、创新点突出、参考文献规范）
- **结论**：发了 SCI 不等于毕业论文能过盲审，毕业论文要按盲审标准提前准备
- **结果**：学生了解盲审机制和避坑要点

### 案例 6：导师放羊没人带的自救路径
- **问题**：导师放羊没人带，不知道怎么自救
- **方法论的使用**：靠文献阅读建立科研逻辑体系 → 从中文优秀博士论文开始入门 → 用思维导图重构文献逻辑 → 自己把课题想清楚，不依赖导师
- **结论**：导师放羊也能自救，关键是靠自己建立科研逻辑体系
- **结果**：学生明确了导师放羊时的自救路径

## A2  触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. **实验验证不出假设后的出口支持**，证据复核已有结果，但不知道如何安排投入或选择继续、收缩、转向或停止
2. **课题被抢发后的出口支持**，创新性事实审计已完成，需要重建节奏、投入或后续路径
3. **纠结该不该换课题**，已有事实判断或证据复核，但难以做出继续、暂停或转向决定
4. **实验结果矛盾后的自救**，候选和数据解释已有结果，主要需要处理焦虑、节奏和下一步
5. **科研焦虑**，主要需要稳定情绪、建立有限预算和恢复行动

### 语言信号 (用户的话里出现这些就应激活)

- 「实验验证不出后要不要继续 / 如何安排投入」
- 「被抢发后我该怎么安排节奏、投入或下一步」
- 「已有判断后该不该换课题 / 换题时机 / 换题不慌」
- 「实验结果矛盾后我该继续还是停 / 如何安排投入」
- 「科研焦虑 / 怎么自救 / 保毕业」
- 「化腐朽为神奇 / 矛盾结果怎么用」
- 「experiment failed / scooped / switch topic / research anxiety」

### 与相邻 skill 的区分

- 与 `innovation-judgment` 的区别，innovation-judgment 负责实质重合、GAP 和创新性是否成立的事实审计，本 skill 负责在已有判断基础上的投入、情绪和转向支持。当 query 出现「创新性没了/创新性不足+怎么办/还能做吗/继续死磕」时，先确保事实审计由 `innovation-judgment` 完成，再由本 skill 提供应对策略；不能因用户问“怎么办”而跳过审计。
- 与 `topic-convergence` 的区别，topic-convergence 先解决候选、数据或科学问题如何解释和收敛（选什么做）；本 skill 只在用户主要需要焦虑、投入、节奏或继续/停止/转向支持时介入，或在前置判断完成后提供出口。遇到结果矛盾并询问是否继续时，先按首要未决问题分流：解释问题交 topic-convergence，实质重合/GAP 交 innovation-judgment，出口支持才由本 skill 处理。
- 与 `hypothesis-construction` 的区别，hypothesis-construction 构建假设，本 skill 解决假设验证不出后的应对。

## E  可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行。

### 情况 A：实验验证不出假设后的投入与出口判断

1. **先按首要未决问题完成判断**
   - 首要问题是候选、表型、数据或科学问题如何解释时，先用 `topic-convergence` 或相应分析方法；涉及实质重合、GAP 或创新窗口时，先用 `innovation-judgment`
   - 完成标准：本 skill 接收已完成的科学判断或事实审计，只处理用户主要提出的焦虑、投入、节奏和出口问题

2. **接收证据复核结果并设定有限预算**
   - 核对假设来源、表型状态、技术质量、背景差异和相反结果的解释边界；不重复执行前置分析
   - 写明剩余时间、资源、最低可接受交付和会改变判断的关键证据
   - 完成标准：证据状态、预算、门槛和停止条件可被复述

3. **选择下一出口**
   - 根据前置判断、有限预算和最低门槛，在继续、收缩 claim、差异化重定位、暂缓补关键判别证据、转向或停止中选择
   - 完成标准：根据证据选择相应出口：继续、收缩 claim、差异化重定位、转向/换题、暂缓并补关键判别证据、停止；信息不足时明确暂缓补证，不强行二选一

### 情况 B：课题被抢发或创新性不足

1. **完成创新性事实核对**
   - 若尚未完成核对，回答中必须明确写出“先用 `innovation-judgment` 完成核对”，判断实质重合、GAP、已发表工作真正回答了什么，以及当前项目是否仍有新的可验证窗口；本 Skill 不复制查文献和事实判断，也不能只写“补完核对”后直接替用户做继续或换题结论
   - 完成标准：拿到审计结论及其证据边界；信息不足时明确尚不能据此决定出口

2. **选择与证据相称的出口**
   - 根据审计结论和项目内证据，在继续、收缩 claim、差异化重定位、转向/换题、暂缓并补关键判别证据、停止中选择；核心问题已被同层次证据完整回答且当前项目没有新窗口，或关键表型长期缺少可信证据时，转向/换题只是可能出口之一
   - 完成标准：给出与证据相称的出口；信息不足时明确暂缓并补关键判别证据，不强行二选一

3. **用课题收敛处理转向需求**
   - 审计确认需要转向时，使用 `topic-convergence` 把已有结果收敛为新问题、目标 claim 和最小证据路径；本 Skill 只帮助安排转向过程中的投入与节奏
   - 完成标准：新方向有明确的下一项工作，当前阶段的时间、资源和行动边界清晰

4. **根据审计结论组织差异化重定位**
   - 读取 `innovation-judgment` 已确认的重合范围、独特证据和可验证窗口，安排后续投入、投稿材料和截止点；具体重合判断与新窗口识别不在本 skill 内重复
   - 围绕已确认窗口调整主线，不以更换模型或场景复制对方答案
   - 完成标准：形成与审计结论一致的行动方案，并明确投稿结果和目标层级仍不确定

### 情况 C：实验结果矛盾后的投入与出口判断

1. **先按首要未决问题完成判断**
   - 首要问题是解释候选、数据或科学问题时，先用 `topic-convergence` 或相应分析方法；涉及实质重合、GAP 或创新窗口时，先用 `innovation-judgment`
   - 完成标准：本 skill 接收前置的技术、背景和竞争解释，只处理用户主要提出的情绪、投入和出口问题

2. **接收冲突解释并保留有限预算**
   - 记录技术原因、背景特异、潜在新机制和相反证据的边界；沿用探索/确认区分，不把相反方向改写成一致结论
   - 明确为验证关键判别点还可投入的时间、资源和停止标准
   - 完成标准：冲突解释、剩余预算和会改变去向的证据清晰可追溯

3. **根据前置判断选择下一出口**
   - 技术质量可信且冲突具有可解释背景时，沿用前置的候选窗口与创新性审计；关键证据不可信或无法复现时，按预算选择补证、收缩、转向或停止
   - 完成标准：根据证据选择相应出口：继续、收缩 claim、差异化重定位、转向/换题、暂缓并补关键判别证据、停止；信息不足时明确暂缓补证，不强行二选一

### 情况 D：科研焦虑

1. **短暂稳定情绪，定位焦虑对象**
   - 先区分焦虑来自证据失败、投入去留、论文/方案交付，还是导师与时间压力；不把情绪本身当作换题或继续的证据
   - 完成标准：用一句话写清当前真正要解决的判断
2. **建立有限预算和停止标准**
   - 写明当前交付目标、剩余时间或资源、最低可接受门槛，以及什么结果会让本轮停止、转向或继续
   - 完成标准：目标、预算、门槛和退出条件可被他人复述
3. **只处理高影响问题**
   - 按对核心结论、主线、关键方法或交付的影响排序，默认只保留 3–5 项；区分必须修复、值得处理和仅属润色的事项，并写出判断依据
   - 完成标准：每一项都有影响等级和依据；没有高影响问题时给出停止建议
4. **执行最小下一步并回到出口判断**
   - 选择一个最可能改变判断的动作；结果出来后按条件选择继续、收缩 claim、差异化重定位、暂缓补证、转向/换题或停止
   - 完成标准：下一动作有完成信号和截止点，不开启无期限的反复修改或验证

### 情况 E：导师放羊没人带

1. **靠文献阅读建立科研逻辑体系**
   - 从中文优秀博士论文开始入门，用思维导图重构文献逻辑
   - 完成标准：建立基本的科研逻辑体系

2. **自己把课题想清楚**
   - 不依赖导师，靠文献+数据+预实验三维统一确立课题
   - 完成标准：能清晰说出课题的科学假设、创新点、技术路线

3. **科研交流注意保护核心创新点**
   - 科研交流是双刃剑，交流能获得反馈但也存在被泄密被抢发风险
   - 交流时把握尺度，核心创新点和关键数据不轻易透露
   - 完成标准：明确哪些可以交流哪些需要保护

## 检查点与失败分支

🔴 **STOP 检查点 1（情况 A step 3 之后）**：跨数据冲突的技术原因、样本背景和可重复性是否已经核查。如果仍是可信的相反结果，把它作为候选窗口交由 `innovation-judgment` 审计其 GAP 属性，不得要求所有数据源朝同一方向。

🔴 **STOP 检查点 2（情况 B step 2 之后）**：是否根据审计和项目证据选择了相称出口：继续、收缩 claim、差异化重定位、转向/换题、暂缓并补关键判别证据或停止。信息不足时不得强行二选一；如果选择转向/换题，转到 step 3 基于已有结果开辟新方向，不要只给终止判断不给后续路径，换题不慌的关键是有新方向可走。

- 如果实验验证不出假设（情况 A）但候选来自当前数据、表型已确定且技术质量可信，不要因缺少文献支持或方向不一致急着转向/换题；先判断背景特异和替代解释，再根据证据选择继续、收缩 claim、暂缓补关键判别证据、转向/换题或停止等出口。
- 如果被抢发（情况 B step 4）找不到差异化角度，回到已有数据检查背景、阶段、细胞关系、机制深度和应用窗口；只有当前证据支持的差异才进入挽救路线，不能靠更换模型或场景制造表面创新。
- 如果实验结果矛盾（情况 C）直接慌了，先判断细胞来源是否真的会改变解释且是否有合适的单细胞或其它定位证据；有条件时再确认主要表达细胞，否则从分组、批次、样本组成、效应稳定性和其它匹配证据排查，不把单细胞或 GSEA 当作必经步骤。

## B  边界 (Boundary) ★

### 这个 skill 服务什么课题主线

- 服务「高质量文章常用方法论」的课题主线：在前置科学解释和事实审计完成后，提供心态调整、投入排序、节奏重建与出口支持
- 服务主要困于焦虑、投入、节奏、继续/停止/转向，或已完成创新性审计后需要行动决策的硕博生

### 不要在以下情况使用此 skill

- **具体课题设计**：用 topic-convergence/hypothesis-construction，本 skill 解决心态和自救
- **候选、数据或科学问题的解释与收敛**：先用 topic-convergence 或相应分析方法；本 Skill 根据判断处理投入与出口
- **实质重合、GAP、创新窗口和被抢发事实**：先用 innovation-judgment；本 skill 在审计结论基础上提供继续、暂停、转向或停止支持
- **实验操作**：本 skill 不涉及具体实验操作
- **标书写作**：用 grant-and-opening，本 skill 不涉及标书
- **论文/综述具体改稿**：用 sci-writing-and-revision 或 review-writing；本 skill 只在用户纠结“改不完、是否值得继续改”时提供投入排序、停止标准和情绪稳定，不替代实际改稿
- **纯计算/纯生信项目的实验式失败判断**：本 skill 仅用于节奏调整和证据重评；应按外部验证、稳健性、可复现性、数据泄漏和方法学比较判断，不把“尚未完成实验表型验证”直接当作换题依据

### 常见失败模式

- **没有依据地继续死磕**：在事实审计、证据状态和有限预算基础上设定继续、转向或停止标准，避免把焦虑变成无期限投入
- **重复文献已知做无用功**：花大量时间做文献已知的实验，对文章发表无贡献
- **为故事制造一致性**：为迎合预期而放宽阈值、换候选或过滤相反结果，会掩盖技术问题，也可能丢掉真正的新 GAP；探索性比较合理设置并记录路径不属于这种情况

### 容易混淆的邻近方法论

- `innovation-judgment`：负责具体课题的创新性、GAP、实质重合和被抢发事实审计；本 skill 在其判断基础上提供投入、情绪和转向支持
- `topic-convergence`：负责宽方向、候选或数据异常的科学问题与证据路径收敛；转向后的新方向回到该 skill
- `hypothesis-construction`：假设构建（验证不出假设时检查假设是否纯空想）
