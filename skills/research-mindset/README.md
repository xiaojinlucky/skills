# Research Mindset

实验受阻、结果矛盾、课题被抢发、资源有限或导师支持不足时，需要重新想清楚节奏和下一步，使用这个 Skill。

## 适合什么时候用

你已经有一些结果或前置判断，当前更需要决定继续、缩小目标、暂停、转向还是停止。

## 使用时带上

失败、矛盾、被抢发或焦虑的具体背景，以及已有结果、剩余时间和资源限制。

## 你会得到

当前难题、证据复核、还能用的结果、下一步，以及继续、缩小目标、转向、暂停或停止的依据。

## 使用边界

候选、数据或科学问题尚未解释清楚时，先使用相应专业 Skill。这个 Skill 处理投入与节奏判断，不代替课题设计、实验操作或创新性核验。
