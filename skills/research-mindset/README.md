# Research Mindset

处理实验做不出、结果矛盾、课题被抢发、换题判断、科研焦虑和导师支持不足时的节奏与证据重评。

它不替代具体课题设计、实验操作、标书写作或创新性评估；纯计算项目按外部验证、稳健性、可复现性和方法学比较判断。

输出应包含当前阻塞、证据复核、继续/收缩/转向决定、可复用结果和下一行动。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

说明失败、矛盾、被抢发或焦虑的具体背景，以及已有结果和资源限制。

## 配置

无需额外配置；当前制度、文献和数据事实须由宿主实际核验。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。它处理节奏与证据重评，不替代具体课题设计、实验操作或标书写作。
