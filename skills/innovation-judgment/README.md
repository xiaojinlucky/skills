# Innovation Judgment

具体课题已经成形，需要核对它与已发表工作之间的实质重合、创新空间和调整条件时，使用这个 Skill。

## 适合什么时候用

你已经有候选、目标背景和初步证据，想知道哪些部分已知，哪些部分仍值得继续核对。

## 使用时带上

候选关系、研究背景、现有数据，以及最接近的已发表工作或需要核对的文献范围。

## 你会得到

已知、部分已知、矛盾、GAP 和新窗口的区分，并得到继续、缩小目标、换个角度做或换题的依据。

## 使用边界

创新判断不承诺期刊层级或发表结果，也不代替具体机制设计、实验排期和正式文献核验。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后说明候选课题、研究背景和最接近的工作。

## 配置与运行环境

无需额外配置；文献范围和当前规则需要按实际来源重新核对。
