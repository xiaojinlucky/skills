# Innovation Judgment

评估课题与已发表工作的实质重合、创新窗口和换题/重定位条件。

它不以论文篇数、机制层数、rescue 数量或期刊分数替代科学问题与证据判断；机制主创新、网络、图谱、资源和纯计算项目按自身 claim 评估。

输出应区分已知、部分已知、矛盾、GAP 和新窗口，并给出继续、收缩、重定位或换题的依据。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供候选、目标背景、现有数据和最接近的已发表工作。

## 配置

无需额外配置；文献核验使用宿主可用的学术检索能力。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。创新判断不承诺期刊层级或发表结果，也不替代具体机制设计和实验排期。
