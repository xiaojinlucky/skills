# 创新性判断

## R  核心论点 (Reading)

在经典的单基因/单分子、表型驱动课题中，创新性判断通常**优先确认表型创新**；这不是所有研究类型的普遍公式。若主 claim 是机制、方法、资源、图谱、网络、临床关联或预测，应按该 claim 的实质新颖性和证据要求判断。表型新颖时机制深度可以相应收窄，但不能据此把机制创新一概视为零。

创新性不能用论文篇数机械量化。判断要比较已发表工作是否已经在相同背景、相同细胞关系、相同方向和关键证据层级上完整回答了本课题的问题，同时检查当前数据是否产生了新的阶段特异、背景特异、矛盾或机制窗口。论文数量用于了解竞争密度，不是候选淘汰阈值。

没有既有高水平论文支持不能自动成为候选降级理由。候选若来自当前数据，技术质量可信且有多个独立证据相互支持，应继续判断它是真正的 literature GAP、新背景、新细胞关系还是间接机制线索，并评估实验验证价值。

创新可粗分为原始突破、二次创新或移植性创新、量变到质变和模仿中迸发四类；这只是讨论问题与证据层级的框架，不是硕博阶段、期刊等级或成功概率的硬标签。别人研究过的主题/分子/细胞仍可做，但不能只靠换条件、换模型或换组合制造表面差异。

核心创新点被抢发后不要机械放弃。若实质比较后仍有当前证据支持的独特窗口，可参考**差异化重定位三策略**：标题重组（不把已被抢发的核心表述继续作为唯一卖点）+ highlight 强调独特创新性（明确与抢发文章的实质差异，如上游调控）+ 直面抢发文章（在讨论部分如实引用并界定重合范围）。是否继续投稿及目标层级取决于剩余创新、证据完整性和期刊判断，不构成发表保证。

科研交流中要**避免被泄密被抢发**：交流时只分享思路框架不分享核心创新细节，提问时只需要针对关键的一个或两个变量（最创新的那一环）代指就够了，不需要将所有课题信息都模糊代称，隐藏太多不便于整体把控。

## I  方法论骨架 (Interpretation)

创新性判断要解决的核心问题是，已有具体课题与发表工作实质重合在哪里、是否仍有 GAP 或创新窗口，以及在这些事实基础上如何判断继续、收缩、重定位或换题和投稿层级。

对经典单基因/单分子、表型驱动课题，可用 A-B-C-D 模型辅助定位：A-D 关系偏向表型问题，B-C 关系偏向机制问题。通常先看表型是否已被实质回答，再判断机制深度是否足以支持当前 claim；机制主创新、网络、方法、资源、图谱和纯计算项目不能被强塞进“表型优先、机制为零”的公式。

创新性判断比较的是科学问题和证据链的实质重合，不是论文计数。别人研究过相关主题仍可做，但不能仅靠换条件、换模型或换组合制造表面差异；要说明当前课题自己的数据产生了什么新现象、新关系、矛盾或未解释窗口。只有核心问题已被同层次证据完整回答，而且当前项目没有新的可验证问题时，才应考虑换题。

若实质重合审计后仍存在当前证据支持的独特窗口，可用差异化重定位三策略组织投稿材料：标题重组、Highlight 强调实质差异、讨论中如实引用抢发文章。三策略只是写作和定位工具，不能替代新增证据，也不能保证继续投稿或达到某一刊物层级。

科研交流中避免被泄密被抢发：交流时只分享思路框架不分享核心创新细节。提问时只需要针对关键的一个或两个变量（最创新的那一环）代指就够了，不需要将所有课题信息都模糊代称，隐藏太多不便于整体把控。

## A1  典型应用案例 (Past Application)

### 案例 1：NETs+METTL3 国自然机制创新性判断
- **问题**：学生想用 METTL3-PARP1 轴做国自然，不知道创新性够不够
- **方法论的使用**：查文献厘清 METTL3-PARP1 关系在哪些癌种、细胞背景和证据层级已被直接回答 → 回到当前组学数据寻找本课题特有的异常和机制窗口
- **结论**：不能因相关关系被报道就直接照搬或直接判死；应判断当前项目是否有自己的新信号，若没有再换方向
- **结果**：学生明确了组学找机制的完整流程

### 案例 2：去泛素化酶+焦亡青基标书创新性评估
- **问题**：学生青基课题（A去泛素化酶→B底物→C焦亡），不知道创新性和逻辑纵深够不够
- **方法论的使用**：创新性分析（A-C 表型创新+A-B 机制创新，B-C 已知）→ 创新程度足够但逻辑纵深不够
- **结论**：该案例中可通过厘清 A-D 表型差异并补足与申请类别相称的机制纵深来增强论证；实际是否足够取决于问题重要性、现有证据和当年评审标准，不把“两层机制”或表型创新当作通用保证
- **结果**：学生明确了标书调整方向

### 案例 3：肺癌+USP1+免疫逃逸换基因
- **问题**：国自然课题 USP1 介导肺癌免疫逃逸，申请两次失败，不知道问题在哪
- **方法论的使用**：USP1 在肺癌免疫中的核心问题和证据链已高度重合 → 当前数据未显示新的细胞背景、阶段差异或机制窗口 → 回到组学数据无偏筛选新的候选
- **结论**：换基因的依据是核心问题已被实质回答且当前项目没有新信号，不是相关论文数量多
- **结果**：完整的换基因+新课题设计流程

### 案例 4：肝细胞癌+D药+PGAM1 聚焦创新
- **问题**：学生做 D 药-PGAM1-肝癌，但前期实验重复了文献已知的东西
- **方法论的使用**：前期做的 D 药抑制肝癌细胞增殖/迁移/凋亡是文献基本已知的→浪费→核心创新点是 D 药抑制 PGAM1 蛋白水平
- **结论**：聚焦创新点（D 抑制 PGAM1 蛋白水平），一切围绕这个开展
- **结果**：聚焦创新点后形成了可继续评估的候选证据链；期刊层级需结合结果质量、主张范围和目标期刊另行判断

### 案例 5：复旦大学 Cell vs 武汉大学 Developmental Cell 抢发挽救
- **问题**：武汉大学团队做具有抗原呈递能力的中性粒细胞+靶向增强抗肿瘤免疫，投稿前一周复旦大学团队的 Cell 文章发表了高度重合的核心创新点，且 Cell 文章做了泛癌+真正靶向增强免疫治疗，武汉大学只做了非小细胞肺癌+只看了关系没做实验证实
- **方法论的使用**：挽救三策略。标题重组（被抢发的「中性粒细胞抗原呈递能力」核心创新点不再出现在标题中）→ highlight 强调独特创新性（武汉大学做了上游 IL-8 调控抗原呈递中性粒细胞，复旦大学没做上游，把 IL-8 放在 highlight 最前面两次强调）→ 直面抢发文章（在讨论部分引用复旦大学 Cell 文章，不逃避，弱化被抢发的抗原呈提能力，强调自己的上游创新）
- **结论**：核心创新点被抢发后，若仍有实质独特且有证据支持的窗口，可以通过差异化重定位重新评估投稿价值；关键是如实界定重合与差异，不把策略本身当作发表保证
- **结果**：案例中团队形成了差异化投稿方案并最终发表；该个案结果不能外推为其他项目必然达到某一刊物层级

### 案例 6：科研交流避免被泄密被抢发
- **问题**：学生想在科研交流中请教课题问题，但担心核心创新点被泄密被抢发
- **方法论的使用**：交流时只分享思路框架不分享核心创新细节。提问时只需要针对关键的一个或两个变量（最创新的那一环）代指就够了，如课题假设是「TP53→衰老通路→CXCL10 表达增加→激活免疫」，只需要将 TP53 或 CXCL10 其中一个关键基因用 A 基因代指，不必将所有环节都模糊代称，隐藏太多不便于整体把控
- **结论**：科研交流要平衡请教和保密，只隐藏最创新的那一环，不要过度隐藏影响交流质量
- **结果**：学生学会了在科研交流中保护核心创新点的同时获得有效建议

## A2  触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. **纠结课题创新性够不够**，有了课题方向但不确定创新性是否足够发文章
2. **具体课题别人做过后还能不能做**，发现相似研究已发表，不知道自己的核心问题是否仍有窗口
3. **评估能发几分 SCI**，想知道当前课题的创新性对应能发什么级别的文章
4. **具体课题的核心基因/主线被抢发**，课题推进中发现别人已经发表了类似研究
5. **判断具体课题该不该换基因/换方向**，课题做了一段时间，创新性一直被质疑

### 语言信号 (用户的话里出现这些就应激活)

- 「我的课题创新性够吗」
- 「这个具体课题还能做吗 / 别人做过后我的核心问题还能做吗」
- 「能发几分 SCI / 能上一区吗」
- 「表型创新和机制创新哪个重要」
- 「被抢发了怎么办 / 该不该换基因」
- 「研究烂了是什么意思 / 多少篇算烂」
- 「我的 USP1/XX 具体课题研究太多了还能做吗」
- 「innovation / novelty / can I still do this / saturated area」

### 与相邻 skill 的区分

- 与 `topic-convergence` 的区别，topic-convergence 解决「怎么从大方向、候选或数据异常收敛到具体课题」（选什么做），本 skill 解决「这个已有具体课题的实质重合、GAP 和创新窗口如何判断」（还能不能做、能发几分）。先收敛再审计创新。
- 与 `mechanism-design` 的区别，本 skill 判断机制创新是否需要（表型创新够则机制创新可部分或没有），mechanism-design 解决机制怎么做。
- 与 `research-mindset` 的区别，本 skill 判断创新性够不够、该不该换题，research-mindset 解决换题后的心态调整和科研节奏重建。先判创新再调心态。
- 与 `grant-and-opening` 的区别，本 skill 判断创新性本身，grant-and-opening 把创新性放进标书框架评估（含机制纵深+前期完成度）。判断创新性够不够用本 skill，评估标书结构够不够用 grant-and-opening。

## E  可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行。

1. **按主 claim 拆解创新单元**
   - 经典单基因/单分子、表型驱动课题可用 A-B-C-D 模型定位：A-D 关系偏向表型，B-C 关系偏向机制；网络、图谱、空间、多组学、资源、方法或预测课题按其核心关系、状态、任务或资源对象定义比较单元
   - 完成标准：明确写出当前主 claim 的核心创新单元、比较背景和证据层级

2. **判断核心 claim 的实质新颖性**
   - 候选应先来自当前数据、异常或未解释现象；随后查文献比较核心创新单元是否已在相同背景、任务、对象、方向和证据层级被完整回答。经典表型驱动课题优先检查 A-D 关系，机制主创新或其它主 claim 按其自身问题判断
   - 调用 `nature-academic-search` 检索与核心创新单元匹配的疾病、对象、关系或任务，逐篇核对直接关系、研究背景和证据层级；记录数量只反映竞争密度
   - 完成标准：给出 known / partial-known / contradictory / GAP / novel 的语义判断，并说明真正重合和差异在哪里
   - 判停条件：如果核心问题已被同层次证据完整回答，而且当前项目没有新的可验证信号，跳到 step 5 判断是否换题

3. **判断机制创新性（次要）**
   - 查文献确认 B-C 关系的已知边界、背景依赖和证据层级，不按篇数直接定级
   - 调用 `nature-academic-search` 检索「B 机制 + C 节点 + 目标疾病」
   - 完成标准：给出与主 claim 相称的机制创新判断，并说明证据边界
   - 注意，在表型驱动课题中机制创新可以部分或没有；机制主创新、网络、方法、资源、图谱和纯计算项目应按各自主张判断

4. **匹配问题深度与项目资源**
   - 根据问题的重要性、新现象的清晰度、机制深度、因果证据需求和可执行资源判断项目体量
   - 完成标准：明确当前问题需要做到的证据层级，并与硕博阶段和实验条件匹配

5. **判断具体课题是否需要换基因/换方向**
   - 触发换题的条件：核心问题已被同层次证据完整回答、当前项目没有新的背景或机制窗口，或者自己的关键表型长期缺少可信证据
   - 换题不意味着之前结果都不能用，基于已有结果可开辟新方向
   - 完成标准：在证据足以支持决策时，给出最合适的出口：`继续`、`收缩 claim`、`差异化重定位` 或 `换基因/换方向`，并说明触发依据。信息不足时明确待核验事项，不为了完整而强行四选一

6. **被抢发后的差异化重定位（条件性）**
   - 触发条件：核心创新点被抢发但仍有独特创新点（如上游调控、不同模型、不同疾病）
   - 策略一标题重组：被抢发的核心创新点不能再出现在标题中，否则审稿人容易质疑创新性
   - 策略二 highlight 强调独特创新性：分析与抢发文章的不同之处（如做了上游调控而抢发文章没做），把最创新的东西放在 highlight 最前面
   - 策略三直面抢发文章：在讨论部分引用抢发文章，不能掩耳盗铃避而不谈，否则审稿人检索发现会留负面印象
   - 完成标准：给出三策略的具体执行方案（新标题+highlight 要点+讨论引用方式），并明确实质重合、独特证据和投稿层级的不确定性；不承诺发表结果

7. **校准发表层级，不机械估分**
   - 综合科学问题的重要性、创新的实质、证据与 claim 的匹配度、机制或因果深度是否必要、领域竞争窗口和目标期刊实际范围判断
   - rescue 数量、机制层数或“表型创新+机制创新”的组合不能直接换算影响因子
   - 证据尚不足时明确还缺什么，不给虚假的分数区间保证
   - 完成标准：给出有依据的目标层级判断、主要不确定性和会改变判断的证据

8. **提问时保护创新点**
   - 科研交流中请教问题时，只分享思路框架不分享核心创新细节
   - 提问时只需要针对关键的一个或两个变量（最创新的那一环）代指就够了，如课题假设是「TP53→衰老通路→CXCL10 表达增加→激活免疫」，只需要将 TP53 或 CXCL10 其中一个关键基因用 A 基因代指
   - 不要将所有课题信息都模糊代称，隐藏太多不便于整体把控
   - 完成标准：给出交流时的代指方案（哪一两个变量需要代指，其余可正常交流）

## 检查点与失败分支

🔴 **STOP 检查点 1（step 2 之后）**：当前主 claim 的核心问题是否已被同层次证据完整回答，且当前项目没有新的背景、阶段、细胞关系、矛盾或机制窗口。如果是，跳到 step 5 判断换题；否则继续评估，不得用论文篇数代替判断。

🔴 **STOP 检查点 2（step 5 之后）**：是否给出了与证据相称的去向判断：继续、收缩 claim、差异化重定位或换基因/换方向。如果判断是换题，转到 research-mindset 处理换题心态；如果判断是收缩或重定位，也要说明保留什么、放弃什么，不要只给标签。

- 如果 `nature-academic-search` 返回几百篇宽泛记录，收紧疾病、细胞背景、表型和关系词，核对真正直接相关的工作；不要用模糊数量估算创新性。
- 如果被抢发但仍有独特创新点（上游调控、不同模型、不同疾病），不要仅凭标题差异判断能否挽救；先完成实质重合审计，再把 step 6 三策略作为条件性重定位方案，不能承诺发表结果。
- 如果用户纠结「能发几分」但表型和机制创新性都还没判断，先做 step 2 和 step 3，分数估算（step 7）依赖前面的创新性判断，不能跳步。

## B  边界 (Boundary) ★

### 这个 skill 服务什么课题主线

- 服务需要对已有具体课题进行实质重合、GAP、创新窗口和投稿定位审计的科研主线；单基因/单分子+表型+机制是其中的高频默认路径
- 服务需要依据事实判断具体课题是否继续、收缩、重定位或换题的硕博生和青年临床医生

### 不要在以下情况使用此 skill

- **原始突破性发现**：本 skill 仍可帮助绘制已知边界，但不能用论文数量、期刊等级或既有范式压低当前数据产生的新现象；突破性候选应由证据质量、解释力和可验证性判断
- **机制创新作为主创新点的例外**：A-D 关系已知但机制完全新颖（如发现新的翻译后修饰类型、新的相分离机制、新的调控模式），这类文章表型不新但机制创新足够发 CNS，不适用「表型创新是 1 机制创新是 0」的判断
- **多基因协同/通路网络、图谱、空间或多组学课题**：按其主 claim 的实质重合、GAP、创新窗口和证据层级审计，不套用单基因的表型/机制公式
- **纯计算生物学/纯生信方向**：不直接套用「表型+机制」实验评分；可按预测、图谱、资源或方法学 claim 评估创新性。若主张因果机制，另需相称的独立验证，不把实验范式当作唯一入口
- **标书创新性评估**：标书评估还需机制纵深+前期完成度，用 grant-and-opening

### 常见失败模式

- **重复文献已知做无用功**：花大量时间做文献已知的实验（如某药抑制某癌细胞增殖/迁移/凋亡），对文章发表无贡献
- **不换题死磕创新性不足的课题**：课题创新性不足或被抢发后不换题继续死磕，浪费大量时间和经费

### 容易混淆的邻近方法论

- `topic-convergence`：把宽方向、候选或数据异常收敛为具体课题（本 skill 前置）
- `mechanism-design`：设计机制（本 skill 判断机制创新是否需要后用）
- `grant-and-opening`：标书创新性评估（本 skill 进阶，加入机制纵深+完成度）
- `research-mindset`：在本 skill 完成事实审计后，处理情绪、投入、节奏和继续/停止/转向出口
