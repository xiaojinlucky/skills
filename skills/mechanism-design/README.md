# Mechanism Design

在表型或稳定候选已经出现后，设计能区分竞争解释的机制方案。

可处理组学、扰动、蛋白互作、调控关系和细胞状态；观察性或纯计算结果默认只能支持关联、解释模型或待验证机制，不能单独升级为因果或直接作用。

输出应包含候选来源、证据等级、竞争解释、最小验证链、判停条件和下一交接。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供稳定表型、候选关系、当前证据和最担心的竞争解释。

## 配置

无需额外配置；具体组学和实验执行由宿主可用的执行能力完成。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。观察性或纯计算结果默认不单独支持因果、必要性、充分性或直接作用。
