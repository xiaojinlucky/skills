# Mechanism Design

表型或已有明确候选，需要设计能够区分竞争解释的机制验证方案时，使用这个 Skill。

## 适合什么时候用

你已有候选关系，想决定哪些组学、扰动、蛋白互作、调控关系或细胞状态证据值得优先验证。

## 使用时带上

已有表型、候选关系、当前证据，以及最担心的竞争解释和资源限制。

## 你会得到

候选来源、证据等级、竞争解释、最低验证链、判停条件和下一步怎么做。

## 使用边界

观察性或纯计算结果通常只能支持关联、解释模型或待验证机制，不能单独支撑因果、必要性、充分性或直接作用。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后描述表型、候选关系和最担心的替代解释。

## 配置与运行环境

无需额外配置；实验实施仍以实际平台、伦理和安全要求为准。
