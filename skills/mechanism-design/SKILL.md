# 机制设计

## 独立责任

- **进入条件**：当前数据、异常、扰动或预实验已经产生值得解释的表型/候选关系。
- **唯一决定**：哪些机制候选由当前课题证据支持，哪条验证链能最有效地区分竞争解释。
- **退出条件**：得到有证据来源、优先级、替代解释、关键实验和判停条件的机制方案。
- **下一步工作**：具体分析选择相应的方法，因果强度使用 `causality-rescue`，实验排期使用 `pre-experiment-design`，主线取舍使用 `topic-convergence`。

表型尚未稳定、候选完全来自论文或用户只要纯生信执行时，不用本 Skill 强行搭机制链。

观察性或纯计算项目也可以形成机制模型、预测性关系或候选通路，但默认输出仍是关联、解释模型或待验证机制。只有存在独立验证、时间顺序、自然实验、扰动或其它与 claim 相称的证据时，才可升级为因果、必要性、充分性或直接作用；不要把通路富集、共表达或预测结果单独写成机制已被证明。

## Discovery-first

机制候选默认按下面顺序产生：

```text
当前课题的表型、异常或扰动
→ 无偏描述改变了哪些 cell / state / program / pathway / interaction / molecule
→ 检查效应、稳定性、背景特异性和技术替代解释
→ 形成少量候选与竞争机制
→ 文献划定 known / partial-known / contradictory / gap / novel
→ 选择能区分候选的实验
```

文献可以提供方法、发现路径、对照、证据升级和解释框架，不能因为明星通路更熟悉就把它自动排在当前数据的新信号之前。没有高水平论文先例不是淘汰理由；来自当前数据且技术可信的 literature-negative 信号应继续判断是否构成新背景、阶段或细胞关系。

## 机制不是固定两层模板

根据当前科学问题选择合适层次：

- **功能关系**：候选变化是否解释当前表型；
- **调控关系**：上游扰动是否改变候选，下游是否随之变化；
- **直接作用**：结合、修饰、酶底物或空间接触是否有直接证据；
- **细胞关系**：sender / receiver、状态转换或细胞间信号是否解释现象；
- **网络机制**：多个节点或 program 共同作用，不能强压成单基因线性链；
- **非机制研究**：图谱、预测、资源、方法学或纯计算课题不必为了“像机制论文”补一条湿实验链。

CO-IP、质谱、TF、m6A、甲基化、GSEA、单细胞通信等只是候选工具。先问它们能区分哪两个解释，再决定是否使用；不按工具清单反推故事。

## 工作流

### 1. 写清要解释的现象

用一句话说明当前表型/信号、证据等级和仍未解释的关系。若当前只有相关性，明确它是候选，不把“表型已确定”伪造为事实。

### 2. 从项目内证据生成候选

按数据类型检查真正改变的对象：效应量、重复性、方向、样本/供体一致性、细胞或阶段特异性、扰动响应、正交数据和技术质量。使用成熟软件、统计方法和 pipeline；不为创新性重新造分析工具。

候选数量由证据决定。优先保留彼此能解释不同现象或代表不同竞争机制的少量候选，不用固定“前 10 通路”“必须 1 个靶点”或文献数量评分。

### 3. 排除最可能的技术解释

只检查会改变候选去留的问题，例如批次/供体、功效不足、组成变化、测量偏差、阈值敏感性或模型特异性。已有检查足以支持方向时停止，不追加一般性稳健性套餐。

### 4. 候选形成后查文献

把文献角色显式判断为方法参考、发现路径、已知空间、GAP、发现后解释或用户明确的复现目标。记录候选属于已知、部分已知、矛盾、GAP 还是潜在新发现；不得用论文答案替换本项目候选，也不得把自己的相反结果修剪到论文方向。

### 5. 设计能区分竞争解释的验证

对每个核心候选写：

- 当前观察支持什么、不支持什么；
- 最强替代解释是什么；
- 哪个最小实验会让两条解释得到不同结果；
- 阳性、阴性或矛盾结果分别怎样改变机制图和下一步。

相关、去除/抑制、增加/激活、回补、直接结合、时序、空间定位和独立模型各回答不同问题。只有核心 claim 真正需要该证据时才加入；不机械要求每条边都有全部实验。

### 6. 按信息增益排序

优先级综合：对主线的解释力、当前证据、可证伪性、实验可行性、竞争窗口和失败后仍能学到什么。期刊分区或影响因子不能由“做了几层机制/有没有 rescue”直接预测，也不作为设计实验的替代标准。

## 典型路线

- **扰动组学**：扰动 A 后观察 program/pathway → 不同样本或正交方法复核 → 文献定位 → 设计区分性验证。
- **蛋白直接作用**：先确认直接作用会改变核心解释，再选择 CO-IP、质谱、pull-down、定位、酶活或底物验证；阴性结果要能回到间接机制。
- **单细胞/空间**：区分组成变化与状态变化，先由当前数据识别特异 cell state / interaction，再决定是否需要 sender-receiver、空间邻近或功能扰动。
- **上游调控**：基于当前数据与生物学属性比较 TF、表观修饰、降解、代谢或环境信号；不在缺少证据时掷硬币。

## 失败分支

- 候选只来自论文：回到当前数据或明确把任务改成复现/验证。
- 候选不稳定：先判断技术质量和背景特异性；关键证据失败就降级或更换，不靠更多文献挽救。
- 直接实验阴性：判断是方法失效、条件不对还是间接机制；只补能区分这些情况的检查。
- 多个候选并存：设计一个能最大化区分度的实验，不让每条线同时长成完整故事。
- 发现与文献相反：保留真实结果，把冲突当作可能的 GAP，并优先排除技术解释。

## 输出

1. 当前可支持的机制判断与证据等级；
2. 候选来源和文献角色；
3. 主要竞争解释；
4. 按优先级排列的最小验证链；
5. 每项结果如何改变下一步；
6. 明确判停条件和下一项验证工作。

不把建议实验写成已经完成，不用期刊分数承诺发表结果。
