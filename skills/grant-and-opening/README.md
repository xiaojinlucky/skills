# Grant and Opening

把已有科学问题、创新窗口、前期证据、目标和风险组织成与具体资助或开题要求相称的方案。

正式制度、年份和评审要求必须以当前官方来源核对；本 Skill 不用固定机制层数、完成百分比或 rescue 数量预测中标。

输出应区分科学判断与材料表达，并给出证据缺口、风险控制和下一交接。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供材料类型、申请类别或开题要求、当前科学问题和前期证据。

## 配置

无需额外配置；正式制度与评审要求应由宿主检索并核对官方来源。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。它组织科学方案与材料，不替代具体实验执行或当前官方制度核验。
