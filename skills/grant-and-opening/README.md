# Grant and Opening

已有科学问题和前期证据，需要写成开题、标书、进展报告或科研计划时，使用这个 Skill。

## 适合什么时候用

你已经有研究问题、目标和一部分证据，需要把科学主线写成符合具体材料要求的方案。

## 使用时带上

材料类型、申请类别或开题要求、当前科学问题、前期证据、资源和主要风险。

## 你会得到

题目、摘要、立项依据、研究目标、创新点、技术路线、可行性和风险控制的写法建议。

## 使用边界

年份、项目指南和评审要求需要按当前官方来源核对。这个 Skill 不预测中标，也不代替实验设计和制度核验。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后说明材料类型、研究问题和已有证据。

## 配置与运行环境

无需额外配置；涉及申报要求时按当前官方来源核对。
