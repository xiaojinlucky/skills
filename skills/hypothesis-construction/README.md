# Hypothesis Construction

观察、异常、候选或临床现象已经出现，需要把它们写成可检验的科学假设时，使用这个 Skill。

## 适合什么时候用

你已经看到了项目自己的信号，想明确假设对象、适用背景、可观测预测和反证条件。

## 使用时带上

当前观察、异常、候选关系或临床现象，以及你想检验的关系和已有证据。

## 你会得到

主假设、claim 强度、竞争解释、判别预测、最低充分验证和随新证据更新的规则。

## 使用边界

A-B-C-D 只是表达关系的记号。没有项目内可信观察时，先做入门或把方向缩小，文献不能替代当前项目的假设依据。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后描述当前观察、候选关系和想检验的预测。

## 配置与运行环境

无需额外配置；假设强度应服从当前证据，不依赖特定宿主或项目。
