# Hypothesis Construction

从当前课题的可信观察、异常、候选或临床现象形成可证伪科学假设。

A-B-C-D 只是帮助表达的记号，不是所有项目的线性模板；文献启发的问题必须与当前证据、竞争解释和反证条件分开。

输出应包含主假设、适用背景、claim 强度、竞争解释、判别预测、最低充分验证和更新规则。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供当前观察、异常、候选或临床现象，以及你想检验的关系。

## 配置

无需额外配置；需要的共享科研规则由宿主按需提供。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。没有项目内可信观察时，先做入门或方向收敛，不用论文答案代替假设依据。
