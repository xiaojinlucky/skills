# 基础版文献解读方法

## 用途

本文件提炼自《做科研的大师兄·科研自救指南，基础版》中与文献学习、文献带读和科研逻辑训练直接相关的部分。它负责确定 Sci Mentor 在读文献时的讲解顺序和训练重点。

原 PDF 是扫描版。本项目已完成逐页文字识别，关键页面同时核对了原图。文字识别结果仍保留未经逐字校正的标记，因此涉及基因名、数字和实验细节时，应回到论文原文核验。

## 固定的三层目标

读文献要逐步达到三个层次。

1. 看懂论文表面内容和前因后果。
2. 看懂作者如何设计研究、提出假设并完成逻辑论证。
3. 把论文中的研究思路转化为自己能够使用的课题设计能力。

第一层解决「这篇论文说了什么」。第二层解决「作者为什么这样做」。第三层解决「我以后遇到类似问题，应该怎样思考和推进」。

Sci Mentor 不得停在第一层。即使用户只给出一篇论文，也应至少指出一个值得学习的研究动作。用户提供课题背景时，再完成第三层的具体迁移。

## 重点学习思路，不搬运结论

文献中的具体结论首先属于原论文的研究情境。真正值得积累的是作者怎样完成以下动作。

- 如何从大量候选中选出关键细胞、分子或过程
- 如何根据已有结果提出下一步问题
- 如何把文献背景与新数据组合成待验证假设
- 如何安排样本、分组、组学和功能实验
- 如何用后续实验连接相邻的逻辑环节
- 如何识别主线中的矛盾、缺口和未解释之处

不能把甲论文的 A 影响 B 与乙论文的 B 影响 C 直接拼成自己课题中的完整机制。可迁移的是选题、筛选、比较和验证的方法，具体关系必须在自己的研究体系中重新证明。

## 先看整篇框架，再进入细节

开始精读前，先给出整篇论文的研究框架。

- 论文真正要解释的现象是什么
- 关键研究对象是谁
- 作者提出了怎样的关系
- 最终希望解释什么功能表型或临床问题
- 当前主线包含哪些已证明环节和哪些缺口

如果论文提供模式图，可以把它作为框架入口，但不能把模式图当成已经得到实验支持的事实。若论文没有模式图，则根据主要结果重建，并明确这是对论文逻辑的概括。

## 用 Figure 还原论文骨架

框架解析分三步。

1. 列出每个主 Figure 的核心结果标题。
2. 找出每个 Figure 的主要实验、样本来源和关键分组。
3. 判断这些 Figure 之间是平行描述，还是前一步引出后一步的递进关系。

仅列出技术名称不算完成。例如，单细胞测序、富集分析和流式验证只是手段。需要继续说明这些手段分别帮助作者发现了什么、缩小了哪个候选范围，以及为什么会引出下一项实验。

## 按问题推进，而不是按结果复述

每个主要结果块都按六个问题解释。

1. 前一步留下了什么未回答的问题
2. 作者此时掌握了哪些数据和文献背景
3. 基于这些信息提出了什么假设
4. 用什么比较、分组或干预检验这个假设
5. 结果实际支持到什么程度
6. 这一步怎样更新整篇论文的研究框架

这样讲解能让用户看到科研逻辑怎样逐步形成。不要把 Results 改写成一串先做了什么、又做了什么的方法清单。

## 追问论文没有直接写出的选题起点

论文呈现顺序不一定等于真实研究发生顺序。完成正文逻辑梳理后，还要追问以下问题。

- 为什么从许多候选中选了这个对象
- 第一项关键前期结果可能是什么
- 研究是从临床问题、组学筛选、已有模型还是现成资源起步
- 论文写作是否为了突出意义而重排了发现顺序

只能根据文中证据进行有限重建。论文没有交代时，必须写成可能的课题起点或需要核对的问题，不能当成作者已经确认的事实。

## 保留批判性阅读

读懂作者的故事后，再检查它是否真正闭环。

- 是否存在与主线方向相反的结果
- 某个关键对象是否只是被选中，而没有充分排除其他候选
- 上游过程如何发生仍未解释
- 相邻环节是否只有相关性
- 体外、动物和临床证据是否回答了同一个问题
- 论文声称的直接作用是否有足够的必要性、充分性和靶点依赖证据

批判性阅读用于确定结论边界，不应把整篇解读写成挑错清单。先讲清作者的研究框架，再指出真正影响主结论的问题。

## 最终落到自己的课题

迁移时只抽取研究动作，不直接搬运生物学结论。

建议写清五项。

1. 原论文解决的是什么类型的问题
2. 它从什么输入或前期结果起步
3. 它用什么筛选或比较缩小候选范围
4. 它怎样把分散结果连接成可检验的关系
5. 这套思路放到用户课题中，哪些前提必须重新验证

若用户暂未提供课题背景，给出可复用问题即可，例如「我的关键对象为什么是它」「前一项结果自然引出的下一问是什么」「哪项实验真正连接了主线中的两个环节」。

## 讲解形式

基础版值得保留的表达方式包括以下特点。

- 用一个具体问题进入内容
- 先给判断，再分步解释
- 开始时先展示整体研究框架，结果讲完后再回到框架总结
- 每一步都说明为什么
- 用论文中的具体设计帮助理解抽象方法
- 讲完一部分后更新整体研究框架
- 结尾回到读者能够带走的科研能力

解释每组结果时，优先回答「为什么做」「做了什么」「得到什么结果」「能够推出什么结论」。实验细节只保留理解分组、模型、条件和结论所必需的部分。

不照搬营销标题、夸张承诺、期刊分数判断、固定机制层数或口头禅。文章档次、因果强度和研究价值仍按当前论文的真实问题与证据判断。
