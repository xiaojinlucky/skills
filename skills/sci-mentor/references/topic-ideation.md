# 找课题思路模式

## 来源层级

本文件的 8 个环节是项目级课题设计 workflow。当前只有 4 个环节形成了证据较稳的创作者方法候选，其余环节不得补写成 BioAdvance 的独立方法。

| 环节 | 当前调用层级 |
|---|---|
| 研究情境与约束 | `method-topic-constraints-0001` |
| 共识、争议与缺口 | `method-topic-gap-0001` |
| 候选切口 | 项目 workflow，原合成单元已拒绝 |
| 创新性、价值与可行性 | 项目 workflow，三个动作拆分待验证 |
| 可证伪假设 | `method-topic-hypothesis-0001` |
| 最短证据链 | 项目 workflow，信息增益版本未归因给创作者 |
| Aim、实验与 Figure | `method-topic-aim-map-0001` |
| 继续、停止与转向 | 项目科学守门规则 |

## 适用范围

用于开题、方向选择、创新性判断、从文献迁移方法、从临床问题或预实验形成假设。目标是收敛到可检验、可执行且有价值的一条主线。

找课题思路是文献学习的最终迁移，不是脱离文献进行自由联想。优先借鉴论文如何提出问题、筛选对象、设计比较和连接证据，不直接搬运论文结论。每条候选主线都要说明借鉴了哪一种研究动作，以及该动作放到用户体系中还缺什么前提。

## 输入账本

先整理以下信息。缺失但不会改变路线的项目可标为未知。

- 研究对象和疾病或生物过程
- 当前已知共识
- 用户已有样本、数据、模型和技术条件
- 稳定出现的前期结果，包括负结果和冲突结果
- 时间、经费和毕业或投稿约束
- 已被报道的表型与机制

## 设计流程

### 先定科学问题

问题要具体到研究对象、条件和结局。若样本来源不能承载目标问题，先修正设计，不用增加分析来掩盖错位。

### 找未闭环处

优先寻找以下切口。

- 临床或领域中重要但机制未明的现象
- 同一表型在不同细胞、阶段或模型中的矛盾
- 已有稳定预实验暴露出的新关系
- 已发表研究的筛选方法可迁移，但目标对象和关键前提尚未回答
- 已知表型中真正缺少的中介或边界条件

不要把没人做过等同于值得做，也不要用多篇文献拼接一条看似完整的机制链。

### 同时判断创新性和可行性

每个候选方向检查五项。

1. 科学问题是否重要且具体
2. 哪一部分是真正未知
3. 用户已有数据提供了什么支点
4. 最小验证是否在现有平台可完成
5. 哪个结果会让路线停止

涉及是否已报道、领域热点或最新研究时，必须进行当前文献检索，不能仅凭私有语料或记忆下结论。

### 先表型，后机制

候选因素未被证明影响核心表型时，第一阶段只设计必要的定位、功能获得、功能缺失和可重复性验证。机制由组学、互作、定位、时间顺序或功能结果继续提示，不预先堆叠。

### 收敛候选

最多给三个候选方向，但不为了凑数补足三条。只有研究对象、核心假设或主要资源投入真正竞争的路线才分别列出。同一主线的验证、边界解释和机制展开写成阶段顺序，不拆成多个候选。

每条候选都写清核心假设、已有支点、最小验证、主要风险和停止条件。最后明确推荐一条，并说明为什么现在优先。非推荐方向紧凑比较，推荐方向只展开一次，避免在多个段落重复相同的扰动和停止判据。

### 映射 Aim 与 Figure

当用户按单细胞、空间转录组、动物实验等技术名称组织 Aim 时，不能只把技术名改写成较像科学问题的标题。必须把每个 Aim 真正落到 Figure 证据任务，至少明确以下关系。

| Aim | 要回答的问题 | Figure 证据任务 | 关键比较 | 关键读出 | 当前允许的断言 |
|---|---|---|---|---|---|

输入没有给出研究对象、条件、候选因素或目标表型时，使用清楚的占位符，不补造具体内容。随后逐个执行删除检验。若删除某 Figure 后核心断言和证据链不受影响，该 Figure 降为支持性内容；若 Aim 只能提供描述性差异，不得命名为功能或机制 Aim。

## 推荐输出

### 当前判断

先说明现有想法是否值得推进，问题出在价值、创新、模型、证据还是可行性。

### 已知与未闭环处

分开写领域已知、用户已有和真正未知。

### 候选主线

每条使用相同维度比较，最多三条。

### 推荐方向

明确推荐一个，给出第一阶段最小实验或分析包。

### 决策判据

写明支持继续的结果、需要降级的结果和应停止或换题的结果。

停止前先通过 [reasoning-kernel.md](reasoning-kernel.md) 中的阴性结果有效性闸门。低效力、扰动失败或测量不可靠只能判为需要修复后重测。

### 暂时不要做

指出当前不会改变判断的深层机制、昂贵组学或装饰性分析。

## 纠偏示例

较弱的设计会写：文献提示 A 调控 B，B 又参与 C，因此研究 A 通过 B 影响 C。

更好的设计会写：现有文献只提供生物学合理性。先在目标模型中确认 A 是否改变核心表型 C，并用扰动实验决定 A 是否值得保留。只有 A 的功能效应成立后，才根据数据检验 B 是否位于中介位置。
