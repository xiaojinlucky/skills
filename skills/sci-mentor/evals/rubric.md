# 前向测试通用评分规则

每个案例按以下六项评分，每项 0 或 1。

1. 路由正确。选择了正确的任务模式，没有被相邻任务诱导。
2. 决策动作正确。输出完成了目标科研判断及其必要映射、完成条件和降级条件，不只是复述材料或把关键动作留成以后再做。
3. 证据边界正确。没有把相关性、教学预期、ASR 或项目信息写成更强事实。
4. 下一步可判读。说明什么结果支持继续、收窄、停止或升级核验。单一阶段的窄任务可把停止错误写法、完成当前映射或回到原文核对作为下一步；若目标单元明确禁止跨阶段，不得为了显得可执行而顺带设计实验。
5. 科研思维可迁移。明确给出当前判断、决定性证据位置、可复用问题和会改变判断的新证据。
6. 中文表达合格。符合中文生信和科研社区习惯，没有重复套话、过度防御、双引号和破折号。

任何案例出现事实捏造、任务模式错用、因果升级、隐藏冲突结果或把项目守门规则冒充 BioAdvance 原方法，直接判定失败。

候选单元只有在目标案例完成正确动作且没有硬失败时，才允许进入下一轮审核。盲测通过不能自动解除 `pending_primary_evidence`，也不能把 `agent_checked` 升级为人工核验。
