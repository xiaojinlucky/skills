# Causality Rescue

已有候选关系，但你还不能确定它代表相关、必要、充分、中介还是直接作用时，使用这个 Skill。

## 适合什么时候用

你手里已有观察、先后关系或干预结果，想把因果 claim 写到证据支持的强度。

## 使用时带上

候选关系、已有干预和观察证据、模型限制，以及希望检验或写入论文的说法。

## 你会得到

你会先得到可以支持的表述，以及暂时不能说的部分。
同时会列出最需要排除的替代解释，并给出相应的干预、对照和读出方案。

## 使用边界

复现或外部验证需要明确标注。具体实验遵循平台 SOP、伦理和安全要求。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后直接描述候选关系和想校准的 claim。

## 配置与运行环境

无需额外配置；实际实验仍以你的平台、伦理和安全要求为准。
