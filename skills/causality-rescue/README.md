# Causality Rescue

校准相关、先后、必要、充分、中介和直接作用等因果 claim，并设计最低充分的干预、对照、读出和 rescue。

默认要求候选关系来自当前课题；明确的复现或外部验证任务可以从论文关系进入，但必须标注为 replication/validation，不包装成新发现。

输出应列出能说什么、不能说什么、关键替代解释、实验分支和交接对象。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供当前候选关系、已有干预/观察证据、模型限制和想主张的因果强度。

## 配置

无需额外配置；具体实验操作须符合当前平台、伦理和安全要求。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。rescue 不是所有研究的固定门槛；复现任务必须标注为 replication/validation。
