# 文献横向—纵向综合参考

这份参考用于四类任务：比较多篇论文实际做法、重建一篇关键论文的发现主线、从图文和 Methods 反推隐性操作，以及形成可以继续判断的方向级证据—方法地图。它不要求把每篇论文都读成同样格式。

## 1. 按当前判断提取相关课题元素，再确定这轮要改变的判断

检索和读论文前，按这轮要改变的判断提取最少的相关课题元素；可以形成元素卡，但不要求用户先填完整卡片：

- 背景与对象：疾病/生理背景、细胞/组织/分子对象和关键情境；
- 比较或扰动：组别、时间、治疗、空间、状态或实验操纵；
- 数据与设计：数据类型、样本结构、统计单位和当前证据；
- 当前观察：本课题已看到的异常、矛盾或未解释现象；
- 目标 claim 与 readout：想支持多强的结论，什么结果能区分主要解释；
- Figure 职责：主图要提出问题、产生候选、定位背景、升级证据还是验证关系；
- 资源与下一决策：时间、样本和执行条件，以及什么结果会让项目继续、收窄、转向或停止。

未知项可以保留为未知，不能用论文里的基因、通路、细胞关系或机制轴补空。然后写清楚这轮是要找领域反复出现的实际做法、看懂一篇论文如何推进、判断某种方法能否迁移，还是找值得继续核验的方向。不要先套固定篇数、ABCD/Aim 链或固定图形。

在研究情境和课题元素可比时，优先把 CNS 正刊和高质量大子刊的应用研究组成核心学习集，用于学习问题提出、候选产生、领域主流分析、证据升级和 Figure 分工。方法论文、官方文档和代码负责实现细节、函数、参数与假设；综述负责术语和领域脉络。期刊层级只是来源优先级，不能替代逐篇核对或排斥情境更匹配的其它高质量研究。若没有足够可比的应用论文，扩大来源范围并明确缺口，不制造“领域共识”。

## 2. 横向比较：从功能而不是名字开始

可以用下面的最小表格整理。每一行先说明它与当前课题哪些元素可比：

| 来源 | 要解决的任务 | 输入与分组 | 实际功能操作 | 论文写出的方法名 | 选择或比较规则 | 证据与适用情境 | 可迁移性与不确定性 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 论文甲 |  |  |  |  |  |  |  |

优先对齐输入、操作、输出和情境。只有这些足够可比时，才把不同名称标成“功能等价”；名称相似不代表功能相同。高质量论文中的出现可以提供参考，但不能单独证明某种做法适合当前问题。

标记证据状态：

- **明确写出**：正文、图注、Methods 或补充材料直接说明。
- **功能等价**：名称不同，但输入、操作、输出和情境均有来源支持且足够可比。
- **推断待核实**：从图形、结果或上下游关系反推，尚未在来源中直接找到。

多篇独立应用的一致可以增强“领域中反复出现”的判断，但不是固定数量门槛；如果来源分歧很大，就明确写出分歧，不制造一个虚假的“标准做法”。

## 3. 纵向重建：把论文的内部主线串起来

对会改变判断的关键论文，按下面的骨架合并阅读：

> 观察或未知 → 候选怎样产生 → 做了什么功能操作 → 如何筛选或比较 → 证据怎样升级 → Figure 承担什么论证职责 → 作者允许的解释 → 验证或下一问题

从正文、图、图注、Methods 和必要的补充材料互相核对。可以保留分支，不要把作者的叙事顺序直接当成生物学时间；如果“纵向”指阅读顺序、证据层级或生物学过程，要明示轴的含义。

## 4. 隐性方法功能反推

当论文没有给一个清楚的方法名时，从结果终点倒推：它需要什么输入，执行了什么最小操作，产生了什么输出，输出又支持哪一步判断。然后回到正文、图注、Methods、补充材料或公开代码核对。

所谓 DIY 路线，是把问题拆成可解释的基础操作序列，不是替论文猜一个隐藏工具名。方法的“功能”指测量、比较、筛选、定位或排序等操作角色，不是“促进某通路”之类的生物学功能。

要分开三件事：论文使用了某方法、方法在该数据上产生了结果、目标关系或机制成立。前一件不能自动推出后两件。

## 5. 合成方向级工作地图

方向地图应带来源、情境和证据状态。边优先使用“观察、使用、支持、提示、待验证”等关系词；跨论文共同出现、上下游叙事或相关性不能自动写成“导致”。需要因果判断时，转交相应的因果或机制方法。

一张图只回答一个问题。图太大时拆成横向比较、关键论文主线和方向摘要，并同时给出文字版。地图只是文献组织后的待判断输入；需要落到当前课题时，要重新结合自己的数据、目标 claim、资源和可证伪性。

探索阶段可以在合理范围调整分析、参数、阈值或展示来发现线索，但保留关键选择并标出探索性；不能把事后选择改写成预设，也不能制造信号或隐藏决定性反证。

## 6. 最小交付与停止

最小可用交付只需回答：

1. 横向上哪些实际功能相近，哪些不能合并；
2. 关键论文纵向上怎样从观察走到下一步；
3. 哪些是明确事实、功能等价或待核实推断；
4. 这份地图改变了什么判断；
5. 下一项最值得做什么，以及什么信号下继续、调整或停止。

当新增论文已经不再改变任务定义、共同功能、适用边界、候选问题或下一项判断时停止，不以读完所有论文或画完所有箭头为门槛。
