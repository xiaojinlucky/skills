# 文献挖掘与阅读

## R  核心论点 (Reading)

**看文献重点学思路和方法，不是复制研究结论**。重点关注作者怎样提出问题、无偏产生候选、用什么逻辑和实验方法缩小范围、怎样升级证据。文献可以帮助建立问题空间、学习发现路径并启发待探索关系，但论文里的具体生物学答案不能直接升级为本项目已成立候选；文献启发的关系应标为问题或暂定假设，并由当前数据、异常、模型或预实验继续验证。

文献阅读按目的分三层：速读用于建立领域地图，跳读用于核对具体细节，精读用于重建发现路径和证据链。数量由当前问题、覆盖缺口和停止条件决定，不设固定篇数或一周期限。

来源按职责选择：高质量前沿原始研究用于学习问题框架和发现路径，经典或方法研究用于验证成熟技术，综述和指南用于建立领域地图，学位论文可帮助新手理解术语和研究脉络。影响因子不能替代相关性、方法质量和证据层级判断。

从文献提取找课题六步法：确定研究方向 → 跟踪顶刊文献 → 重建作者的发现路径 → 提取无偏筛选和证据升级方法 → 标出已知边界、矛盾与 GAP → 回到当前课题的数据、异常或未解释现象产生候选。控制变量只能帮助拓展尚未回答的问题空间，不能把论文答案换一个对象后直接变成本项目候选。

找相似文章的方法：根据当前课题已经自行产生的问题和候选，找设计、模型或方法真正相似且证据可核对的研究，参考实验分组、证据层级和验证设计；只迁移设计，不迁移论文里的生物学答案。

查全查准文献是课题立项阶段的关键能力。查全可用 PubMed 主题词、自由词、同义词、引文链和高级检索联合，提高召回和可追溯覆盖，用于判断已有研究边界；任何单一数据库或检索策略都不能证明零遗漏或“所有文献”均已找到。查准用关键词精确检索，用于找具体方法细节。

## I  方法论骨架 (Interpretation)

文献挖掘与阅读要解决的核心问题是，文献太多读不完，怎么高效读、怎么从文献里找到课题切入点。

读文献按目的分三层，不是每篇都精读：速读建立领域地图，跳读核对方法或事实，精读重建少数关键论文的发现过程和证据链。来源选择看当前职责和质量，不按期刊分数机械分工；新手可用清晰综述、指南或学位论文建立术语和脉络，再回到关键原始研究。

精读的核心方法是**框架解析**，看一篇文献时看主体框架而不是沉浸于结果细节。用思维导图重构文献的科研逻辑，把一篇文献拆成逻辑节点和上下游关系，而不是记住一堆结论。框架解析的标准是能复述这篇文章如何筛选基因、用什么逻辑找到机制、基于什么数据切入，而不是只记住「A 基因通过 B 通路影响 C 疾病」这个结论。

从文献找课题用六步法：确定方向 → 跟踪顶刊 → 重建作者的发现起点与筛选过程 → 提取可迁移方法 → 标出已知、矛盾与 GAP → 回到自己的数据、异常或未解释现象形成候选。控制变量可以拓展尚未回答的问题，但不能把别人已发表的生物学关系直接换条件后当成自己的答案。

提问要按格式整理（当前数据或异常+候选假设+文献已知边界+文献未知或矛盾），整理过程本身就是课题清晰化和科研思维训练。发现型任务可以先从文献形成问题空间或暂定工作假设，但必须显式标记其证据状态；不得先用文献填好 A-B-C-D 并把它当作已成立答案，再回数据里寻找支持。

## A1  典型应用案例 (Past Application)

### 案例 1：急性肾损伤+磷酸戊糖途径从文献找课题
- **问题**：学生拿到老板给的大方向（急性肾损伤+磷酸戊糖途径），不会从文献找切入点
- **方法论的使用**：先用文献厘清磷酸戊糖途径与急性肾损伤的已知边界和未解释问题 → 回到当前数据或异常筛选候选基因与亚型特异信号 → 再用文献判断候选属于已知、部分已知、矛盾还是 GAP
- **结论**：六步法用于提取发现路径和定位 GAP，具体候选仍由当前课题证据产生
- **结果**：学生明确了从文献找课题的思路

### 案例 2：纯文献拼接假设陷阱
- **问题**：学生把不同文献报道的结论生搬硬套拼接成假设
- **方法论的使用**：识别 warning signs（假设里所有逻辑节点都「有文献报道」、没有自己数据支持、把其他疾病结论直接套到自己疾病）→ 判断为纯文献拼接陷阱
- **结论**：从文献找课题≠纯文献拼接；没有自己的数据、异常或未解释现象时，可以形成文献启发的待探索问题或暂定工作假设，但不能把论文结论升级为已成立项目候选
- **结果**：学生避免了纯文献拼接的失败模式

### 案例 3：Cancer Discovery 文献框架解析
- **问题**：学生读 SCI 文献时图很多感觉混乱，理不清图之间的逻辑关系
- **方法论的使用**：用思维导图重构文献科研逻辑 → 框架解析看主体框架不沉浸结果细节 → 拆成逻辑节点和上下游关系 → 重点学这篇文章如何筛选基因、用什么逻辑找到机制、基于什么数据切入
- **结论**：框架解析法能突破文献阅读难关，从惧怕文献到享受文献
- **结果**：学生掌握了用思维导图重构文献逻辑的方法，看文献不再混乱

### 案例 4：从中文博士论文入门读文献
- **问题**：科研小白直接读英文 SCI 觉得困难坚持不下去
- **方法论的使用**：从中文优秀博士论文开始（母语不排斥）→ 把读文献变成填空题式流程（先看研究背景→再看逻辑框架→再看实验结果→最后看实验方法）→ 建立科研逻辑体系后再过渡到英文 SCI
- **结论**：入门阶段从中文博士论文开始能降低坚持门槛，先建立逻辑框架概念再读英文文献
- **结果**：学生从惧怕文献到能坚持读下去，建立了基本的科研逻辑体系

## A2  触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. **文献太多读不完**，课题开始时面对海量文献不知道怎么高效读
2. **不知道看哪类文献**，主刊/10-20分/5-10分/博士论文不知道分别用来干什么
3. **从文献找课题切入点**，想从顶刊文献里提取找课题的方法
4. **不知道怎么精读**，精读一篇文章应该学什么（Introduction/Results/Discussion/Methods）
5. **找相似文章参考实验设计**，不知道怎么找和自己课题高度相似的高分文章

### 与相邻 skill 的区分

- 与 `topic-convergence` 的区别，本 skill 解决「怎么读文献+从文献提取找课题方法」（技能层面），topic-convergence 解决「怎么把提取的方法用到自己课题收敛方向」（应用层面）。本 skill 的六步法是 topic-convergence 情况 B（没有组学数据）的前置，topic-convergence 情况 B 会调用本 skill 的六步法提取方法，然后用本 skill 收敛方向。
- 与 `review-writing` 的区别，本 skill 解决读文献找课题，review-writing 解决写综述。
- 与 `research-entry` 的区别，research-entry 解决科研入门整体路径（含读博士论文、分层研究论文和 CNS（Cell、Nature、Science 等高影响力综合期刊）代表作），本 skill 深入文献阅读和挖掘方法。入门阶段的看文献（不知道从哪开始）触发 research-entry，已有入门基础需要深入文献方法触发本 skill。

## E  可执行步骤 (Execution)

当 skill 被激活后，按以下步骤执行。

### 情况 A：课题开始时系统读文献

1. **速读建领域认知**
   - 用查询分组、代表性来源和引用链快速覆盖主要方向、争议、方法与已知边界
   - 完成标准：能说出该领域的主要方向、热点、已解决的问题

2. **按当前职责选择来源**
   - 前沿原始研究：问题框架、无偏发现和证据升级
   - 经典或方法研究：成熟技术、分组和关键对照
   - 综述、指南或学位论文：术语、脉络和已知空间
   - 完成标准：每个来源都能说明为何与当前问题相关

3. **精读练科研思维（框架解析法）**
   - 精读少数真正会改变当前理解、方法或候选判断的关键论文
   - 用思维导图重构文献科研逻辑，拆成逻辑节点和上下游关系
   - 重点学思路方法不是结论：如何筛选基因、用什么逻辑找到机制、基于什么数据切入
   - PDF 提取：用 AI 助手提取 PDF 文本（原生 PDF 直接读，扫描版用 OCR）；复杂版面/表格可用 pdfplumber 辅助
   - 学 Introduction 切入/Results 逻辑/Discussion 长短处/Methods 设计
   - 完成标准：能复述每篇精读文章的课题设计逻辑和找课题方法，而不是只记住结论

### 情况 B：从文献找课题切入点

1. **确定研究方向，跟踪代表作**
   - 可从约 10-20 篇或 20-30 篇相关研究性论文起步，数量只是入门覆盖和方法训练的参考批量，不是完成门槛
   - 完成标准：能说明关键发现路径、主要争议、已知边界和当前覆盖缺口；必要时可少于或多于上述数量

2. **看主图提取切入点**
   - 看每篇第一个主图的课题切入点
   - 完成标准：提取出每篇的「找课题方法」

3. **模型化发现路径**
   - 记录作者从什么异常或未知出发、怎样无偏筛选、如何缩小候选、怎样升级证据
   - 完成标准：形成可迁移的发现方法，不保留论文里的具体生物学答案作为模板槽位

4. **拓展未回答的问题空间**
   - 根据已知边界、矛盾、不同背景和当前数据中的异常形成问题
   - 完成标准：拓展出 3-5 个待探索问题；只有自己的数据或实验产生信号后，才能收敛成具体生物学候选

### 情况 C：查全查准文献

1. **查全（课题立项阶段判断创新性）**
   - 用 PubMed 主题词、自由词、同义词、引文链和高级检索联合，提高召回并记录数据库、日期、检索式和未覆盖盲区；主题词不能保证全面无遗漏
   - 调用 `nature-academic-search` 以多查询策略检索，必要时再由当前任务整理结构化证据表
   - 应用场景：课题立项时定位直接报道、相近报道和检索盲区，评估创新性风险
   - 完成标准：在已声明数据库和检索范围内形成可追溯的代表性证据集，说明已知、部分已知、矛盾、GAP 和仍可能遗漏的范围；不能据此宣称找到所有文献

2. **查准（找具体方法细节）**
   - 用关键词精确检索，直击具体方法、引物、试剂
   - 调用 `nature-academic-search` 做精确检索
   - 完成标准：找到所需的具体方法细节

### 情况 D：找相似文章参考实验设计

1. **根据当前问题找方法相似的文章**
   - 可优先参考与当前问题方法相近的成熟研究，比较实验分组、对照、证据层级和验证路径；期刊分数仅作检索线索，不是质量或数量门槛
   - 完成标准：找到 1 篇方法设计相似的文章，不要求复用其具体候选或机制轴

2. **只参考实验设计和证据组织**
   - 完成标准：对照其设计安排自己的实验，但候选、预期方向和故事由当前课题证据决定

### 情况 E：按格式整理提问

按研究类型使用最小问题合同，不预设线性因果或机制链。至少交代：当前观察/问题、研究类型或目标 claim、文献已知边界、未知/矛盾、当前证据状态、待判别问题和下一步。描述、关联、预测、机制、复现和验证等类型都可使用同一合同；A→B→C-D 只在线性机制问题中作为可选的简写，并不要求其它类型补齐这些节点。

- **当前观察/问题**：写当前数据、异常、现象或待解释问题。
- **研究类型或目标 claim**：标明这是发现、描述、关联、预测、机制、复现或验证等任务，并写清要判断的 claim。
- **文献已知边界**：只列与当前问题直接相关、且证据可核对的已知关系、范围或条件。
- **未知/矛盾**：指出尚未回答、结果不一致或适用条件不清之处。
- **当前证据状态**：区分观察、推断、暂定假设、已报道和已验证，不把文献结论替代项目内证据。
- **待判别问题和下一步**：写最关键的可判别问题，以及能区分主要解释或推进当前 claim 的最小下一步。

发现型任务优先从当前数据、异常或未解释现象出发，再用文献定位已知边界和 GAP，形成候选问题或暂定工作假设。明确复现或验证任务可以从论文关系起步，但须把目标标记为复现/验证而不是新发现。完成标准：合同各项与研究类型和目标 claim 一致，证据状态明确，且下一步直接对应待判别问题。

## 检查点与失败分支

**检查点 1（情况 A step 1 之后）**：当前覆盖能否说清主要方向、争议、方法和已知边界。不能时补具体缺口，不为达到篇数继续无边界搜集。

**检查点 2（情况 A step 3 之后）**：精读后能否复述关键论文的发现起点、筛选过程、证据升级和边界，而不是只记住结论。不能时回到对应论文补这一缺口。

- 如果用户要找课题切入点但连研究方向都没定，先做情况 B step 1 确定方向，不要直接看主图提取切入点，没有方向约束的提取会发散。
- 如果查全查准时检索返回结果太少，换同义词、自由词、主题词、引文链或数据库重检；不要把一次检索的结果当作完整文献全集，也不要用单一关键词就放弃。
- 如果 PDF 提取失败（扫描版或复杂版面），原生 PDF 直接读，扫描版用 OCR，复杂版面用 pdfplumber，三级降级不要卡在一种方法上。

## B  边界 (Boundary) ★

### 这个 skill 服务什么课题主线

- 服务「高质量文章常用方法论」的课题主线：通过系统读文献建立科研思维、学习发现路径并定位已知边界和 GAP
- 服务需要高效读文献、提取可迁移方法和识别未解决问题的硕博生和青年临床医生

### 不要在以下情况使用此 skill

- **具体文献检索工具操作**：本 skill 解决文献阅读和挖掘方法，不解决 PubMed/Endnote 等工具操作
- **单篇文献深度解读**：本 skill 解决系统读文献策略，不解决单篇文章的深度解读
- **综述写作**：本 skill 解决读文献找课题，综述写作用 review-writing

### 常见失败模式

- **纯文献拼接假设**：把不同文献报道的结论生搬硬套拼接成已成立假设，或把论文里的候选换条件后直接变成本项目答案；文献可以启发问题或暂定假设，但升级为项目 claim 前必须补充自己的数据、异常、模型、预实验或明确的复现/验证设计
- **只速读不精读**：只看题目摘要不精读，无法建立科研思维和课题设计能力

### 容易混淆的邻近方法论

- `topic-convergence`：方向收敛（本 skill 后置，从文献提取方法后用）
- `review-writing`：写综述（本 skill 是读，review-writing 是写）
- `research-entry`：科研入门整体路径（本 skill 是入门路径中文献阅读部分的深入）

直接或经总入口使用本 Skill 时，每个任务只读取一次当前宿主提供的共享科研规则中的 `shared/research-core.md`；产生用户可见中文科研内容时再按需读取 `shared/expression-core.md`。这里使用逻辑资源名，不依赖用户目录或宿主私有绝对路径；资源无法解析时明确说明并按最小降级继续，不猜测共享规则。科研创新隔离墙和共同表达只以这两份 shared canonical 为准，本 Skill 不复制第二份。
