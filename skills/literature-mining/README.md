# Literature Mining

读文献需要理解问题如何提出、证据怎样一步步建立和未解之处在哪里时，使用这个 Skill。

## 适合什么时候用

你想从高质量论文中学习发现路径，划定已知边界，并寻找仍可判断、可验证的 GAP；也想比较不同论文实际完成的功能、重建单篇论文主线，或从图文和 Methods 中反推出待核实的隐性操作。方法问题还会并列比较“有名称的专用工具”和“没有固定工具名的 DIY（基础操作组合）路线”，优先查看目标场景中的真实应用论文，而不是停在工具清单。

## 使用时带上

研究方向、当前问题、已有文献或需要重建的发现路径，并说明检索范围。

## 你会得到

证据来源、已知与矛盾之处、GAP、可迁移的方法思路和待验证方向，同时看到当前检索的范围与盲点。方法比较会说明实际操作、代表性实例、收敛或分歧及可迁移边界；需要时还会给出带来源和证据状态的方向级工作地图，以及这份地图改变的判断和下一步。

## 使用边界

具体检索操作、逐段讲解单篇全文和系统综述协议需要相应的方法；但可以重建关键论文的发现主线。文献可以启发问题，当前项目的候选和结论仍需自己的证据支撑，方向地图也不是因果结论。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后说明研究方向、当前卡点和要比较或重建的论文。

## 配置与运行环境

无需额外配置；检索范围、来源和可用全文应在回答中说明。
