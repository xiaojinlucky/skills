# Literature Mining

系统读文献、重建发现路径、划定已知边界和定位 GAP 的方法 Skill。

适合从文献学习作者如何提出问题和升级证据；文献可以启发暂定问题，但不能替当前项目直接生成已成立生物学答案。具体检索工具操作和综述写作另行路由。

输出应包含证据来源、已知/矛盾/GAP、可迁移方法和待验证方向，并标明检索范围与盲点。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供研究方向、当前问题、已知文献或需要重建的发现路径，并说明检索范围。

## 配置

无需额外配置；实际文献检索交给宿主可用的学术检索能力。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。它不替代具体 PubMed/EndNote 操作、单篇全文解读或系统综述的方法学协议。
