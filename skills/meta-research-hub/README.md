# Meta Research Hub

跨阶段、职责冲突或需要排序的中文生物医学科研问题总入口。

它负责恢复科研状态、选择真正拥有独立未决问题的专业 Skill、安排顺序并综合下一行动；清楚的单阶段任务不必经过总入口，零到一开题由 `meta-sci-init` 负责。

输出应包含主判断、当前证据链、参与者及顺序、`methodology_projection` 和下一步状态。共享资源使用 suite manifest 中的逻辑资源名解析，不依赖宿主私有路径。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

在问题模糊、跨多个科研阶段或职责冲突时，直接描述目标、已有证据和限制。

## 配置

无需额外配置；共享资源由 suite manifest 或等价资源解析器提供。

## 兼容性与边界

支持能发现当前 Skills 的宿主。资源或能力不可用时必须报告并最小降级，不猜测路径；清楚的单阶段任务不强制经过本入口。
