# Meta Research Hub

跨阶段、职责冲突或需要排序的中文生物医学科研问题总入口。

它帮助你先说清目标、已有证据、未决问题和资源限制，再选择真正相关的核心方法并排出优先顺序；问题清楚的单阶段任务可以直接使用对应 Skill。

你会得到当前主判断、关键依据、优先顺序、下一步，以及会改变判断的缺失信息。

## 安装

将本目录作为 Skill 安装到支持 Markdown Skill 的宿主中。

## 使用

在问题模糊、跨多个科研阶段、需要在多个方法之间取舍，或不知道下一步先做什么时，直接描述目标、已有证据、限制条件和卡点。

## 配置

无需额外配置；各 Skill 可由支持 Markdown Skill 的宿主直接加载。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。信息或能力不可用时必须明确说明，不猜测；本入口不替代具体实验、数据分析或写作执行。
