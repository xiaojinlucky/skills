# Meta Research Hub

问题跨多个科研阶段，需要在不同判断之间取舍，或你不知道下一步从哪里开始时，从这个 Skill 开始。

## 适合什么时候用

你的课题还没有整理清楚，或同时涉及文献、缩小课题范围、假设、分析、预实验和论文写作。

## 使用时带上

研究目标、已有证据、未决问题、资源限制和当前难题。信息不完整也可以把当前情况说清楚。

## 你会得到

当前阶段的判断、关键依据、该用哪些核心 Skill、下一步，以及会改变判断的缺失信息。涉及方法问题时，不会只罗列工具名称：会先让 `literature-mining` 区分专用工具路线与 DIY（基础操作组合）路线，必要时结合真实应用论文的操作、实例、收敛与分歧。涉及多篇论文时，还会把实际做法横向比较、把关键论文纵向串成主线，并把结果整理成可继续判断的方向地图。

## 使用边界

信息或具体能力不可用时，需要明确说明。这个入口用于整理问题和下一步安排，不代替实验、数据分析或写作执行。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后直接说清当前阶段、证据、卡点和资源限制。

## 配置与运行环境

无需额外配置；它负责科研思路与路由，具体分析、实验和写作由相应工具执行。
