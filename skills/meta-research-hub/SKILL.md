# Meta Research Hub

这是跨阶段科研问题的总入口。它帮助你把目标、证据、未决问题和资源限制放到同一张图里，再决定先处理哪一个判断。

## 什么时候使用

- 课题方向还很宽，不知道从哪里收敛。
- 文献读了不少，却还没有找到可以核验的 GAP。
- 不同分析或实验结果互相矛盾，需要判断先复核什么。
- 假设、机制、预实验、论文或开题材料之间需要安排顺序。
- 资源有限，需要决定继续、收缩、转向或停止。

问题已经明确且只属于一个专业阶段时，直接使用对应的核心 Skill，不必先经过这个入口。

## 工作方式

1. 先确认研究目标、已有证据、当前卡点和资源限制。
2. 判断当前最需要解决的未决问题，以及它会影响哪一项研究决定。
3. 只选择能直接处理这些问题的核心 Skill，按依赖关系安排顺序。
4. 把观察、推断、假设和已经验证的事实分开，避免把文献结论写成当前项目的答案。
5. 优先安排会改变主线或下一步的工作，给每项工作写清完成信号和停止条件。
6. 汇总专业判断，形成下一项行动；信息不足时说明缺口，不猜测。

## 科研判断原则

1. 从当前项目的观察、异常和证据出发。文献用于学习问题如何提出、证据如何推进，以及划定已知边界。
2. 科学问题决定方法。方法需要服务当前 claim、论文主线和实际资源，方法数量本身不代表研究质量。
3. 探索阶段可以调整合适的分析、参数、分组或可视化来寻找信号。关键路径要留有记录，确认性结论要做相称复核。
4. 结论强度服从证据。保留竞争解释和决定性反证，不把相关性写成因果。
5. 有限预算优先用于能改变判断的工作。证据已经足够支撑当前目标时，明确可以停在哪里。

## 输出

回答应至少包括当前判断、关键依据、下一项行动和停止或转向条件。需要多个 Skill 时，说明每个 Skill 要解决的问题和建议顺序。

它不代替具体实验、数据分析、写作执行、伦理审批、临床诊疗、正式统计审查或当前官方制度核验。
