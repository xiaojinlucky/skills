# Topic Convergence

把宽泛方向、当前数据异常或预实验信号收敛成可验证课题候选。

重点判断候选来源、背景特异性、替代解释、创新窗口和支线去留；具体分析或方法选择交给相应的分析执行 Skill。

输出应包含主问题、候选及证据、边界、竞争解释、下一验证动作和交接对象。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。

## 使用

提供宽泛方向、当前异常/候选、可用数据和资源限制。

## 配置

无需额外配置；具体组学分析由宿主可用的执行能力完成。

## 兼容性与边界

支持能加载 Markdown Skill 的宿主。纯生信项目的具体方法选择不由本 Skill 负责，因果 claim 也不能只靠方向收敛成立。
