# Topic Convergence

方向过宽、数据出现异常或预实验有了信号，需要缩小成可验证的课题候选时，使用这个 Skill。

## 适合什么时候用

你有一个大方向、一组候选或一项矛盾结果，想明确研究对象、问题边界、创新空间和下一项验证；也可以把文献形成的方向级证据—方法地图交给它，继续收敛当前问题。

## 使用时带上

宽泛方向、当前异常或候选、可用数据和资源限制。

## 你会得到

主问题、候选及证据、适用边界、竞争解释、下一项验证动作和后续建议。接收方向级证据—方法地图时，会先检查来源、场景、操作/读出和证据状态，选出一条可核实的最小关系，再给出一个主要下一步；文献地图只作为待判断输入，不会被自动写成当前课题结论或因果关系。

## 使用边界

具体组学分析和方法选择需要另找合适的方法。因果 claim 也不能只靠把方向缩小就成立。

## 安装与使用

把仓库地址交给 Agent 安装本 Skill，或使用 `npx skills add https://github.com/xiaojinlucky/skills`；安装后说明宽泛方向、当前异常或候选，以及可用资源。

## 配置与运行环境

无需额外配置；方向地图只作为待判断输入，具体分析和验证仍需相应方法与平台。
