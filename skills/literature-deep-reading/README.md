# 深度读论文

把一篇或少量论文读成可复用的研究逻辑，而不只复述作者的结论。适合组会汇报、课题迁移、研究设计学习和相近研究比较。

## 用途

逐个 Figure 追踪问题、证据和结论边界，识别关键跳步、替代解释和可迁移的分析或实验设计。

## 使用

提供论文 PDF、链接或已经整理的 Figure，并说明你想解决的是组会理解、课题迁移、研究设计还是论文比较。

## 安装

将此目录放入宿主支持的 Skills 目录，或使用宿主提供的 Skill 安装入口。核心入口是 `SKILL.md`。

## 配置

无需额外配置。需要完整全文、补充材料或在线检索时，按宿主实际能力提供相应文件或权限。

## 兼容性与边界

支持能加载 Markdown Skill 的 AI 宿主。缺少论文原文时不会假装完成全文精读；论文已经得到的生物学结论与可迁移的方法和研究逻辑会分开说明。
